# Бэкенд Жэки Коммуналкина

## Демо-данные

`just seed` загружает в пустую базу справочник домов, организации из реестра и
17 демо-организаций в Москве, Санкт-Петербурге и Казани с историей за полгода:
пять из них открыты по демо-ссылкам, остальные видны на карте и в сравнении с
другими УК. Повторный запуск ничего не меняет.
В docker: `docker compose run --rm api python -m zheka.seed`, на развернутом
боте - команда `/seed` в личке.

История кончается днем запуска, а дашборд и бенчмарк считают последние 30
дней. Через две-три недели бенчмарк редеет, через 30 дней пустеет, поэтому
сид лучше запускать как можно ближе к проверке. Чтобы заполнить базу заново,
ее пересоздают, а это стирает квартиры и членство проверяющих, прошедших по
демо-ссылкам.

Сид читает только `zheka/seed/data/` и в сеть не ходит; эти файлы один раз
собрал `scripts/fetch_seed_data.py`.

Что откуда:

- Дома, их год постройки, этажность, площади, число подъездов, взнос на
  капитальный ремонт и управляющая организация - открытые данные АИС ППК
  «ФРТ» (Реформа ЖКХ): наборы «МКД в региональной программе капитального
  ремонта» по Москве, Санкт-Петербургу и Республике Татарстан и «Реестр
  управляющих организаций» от 01.09.2026, карточки домов на reformagkh.ru.
  Телефоны приведены к виду +7XXXXXXXXXX: семизначному номеру добавлен код
  города (812, 843), нерабочие значения вроде «0» и «нет» заменены пустыми.
- В каждом городе 12 улиц по 55 домов. Если карточка дома не называет число
  подъездов или не открылась (часть карточек reformagkh.ru при сборе закрыла
  капча), число подъездов оценено по числу квартир и этажей, а управляющая
  организация у дома не указана.
- Кадастровый номер, износ с датой оценки, состояние дома, если он не
  исправный, и класс энергоэффективности - публичная карточка дома в ГИС ЖКХ
  (dom.gosuslugi.ru). Скрипт ищет дома улицы одним
  запросом по ФИАС GUID из выгрузки Реформы ЖКХ и берет карточку каждого
  найденного дома. Класс энергоэффективности из ГИС ЖКХ важнее класса из
  Реформы ЖКХ. Если ГИС ЖКХ не ответила, у дома остаются только поля Реформы
  ЖКХ. Управляющую организацию и договор управления из ГИС ЖКХ сид не берет:
  демо-организации занимают только дома без УК, новые УК сдвинули бы
  демо-дома, а чужой договор противоречил бы демо-УК в карточке.
- Координаты домов - © участники OpenStreetMap, данные доступны по лицензии
  Open Database License (ODbL) 1.0: https://www.openstreetmap.org/copyright.
  Геокодирование - через Nominatim, а адреса, которых он не нашел, - через
  Overpass API.
- Организации из реестра в сиде не зарегистрированы, у них нет сотрудников и
  истории: для них верно «УК не подключена». Телефон, адрес, почта и сайт -
  из реестра УК Реформы ЖКХ. Заглушки вроде «Net@mail.ru» и «-» и ссылки на
  карточку дома в чужих сервисах скрипт отбрасывает.
- Демо-организации, их сотрудники, жители, лицевые счета, начисления,
  показания, заявки, опросы, объявления, документы и список работ капитального
  ремонта демо-дома - модельные. Названия организаций начинаются с «Демо-УК»,
  их ИНН не проходят контрольную сумму, картинки сгенерированы. Номеров
  лицензий в сиде нет.

## Yandex: распознавание показаний и подсказка категории

Три необязательные переменные окружения:

- `YANDEX_API_KEY` - API-ключ сервисного аккаунта Yandex Cloud;
- `YANDEX_FOLDER_ID` - каталог этого аккаунта;
- `YANDEX_MODEL` - текстовая модель Yandex AI Studio, по умолчанию
  `yandexgpt-5-lite`.

С ключом и каталогом мини-приложение распознает показание счетчика по фото
(Yandex Vision OCR) и подсказывает категорию заявки по описанию (Yandex AI
Studio). Без них продукт работает полностью: распознавание отвечает пустым
значением, подсказка - `category: null`, и житель выбирает категорию
кнопками, как при любом сбое модели. Отвергнутый Yandex ключ (401 или 403)
или ключ с символом не из ASCII выключает подсказки до перезапуска процесса.
Ключу нужна роль `ai.languageModels.user` на каталог.
