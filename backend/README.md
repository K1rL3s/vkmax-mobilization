# Бэкенд Жэки Коммуналкина

## Демо-данные

`just seed` загружает в пустую базу справочник домов, организации из реестра и
пять демо-организаций с историей за полгода. Повторный запуск ничего не меняет.
В docker: `docker compose run --rm api python -m zheka.seed`.
На развернутом боте то же делает команда `/seed` в личке бота.

История кончается днем запуска, а дашборд и бенчмарк считают последние 30
дней от момента, когда их открыли. Через две-три недели после сида бенчмарк
редеет, через 30 дней пустеет. Поэтому сид запускается как можно ближе к
проверке. Пересев - это пересоздание базы, и он стирает квартиры и членство
всех проверяющих, уже прошедших по демо-ссылкам.

Сид читает только файлы из `zheka/seed/data/` и в сеть не ходит. Эти файлы
один раз собрал скрипт `scripts/fetch_seed_data.py`.

Что откуда:

- Дома, их год постройки, этажность, площади, число подъездов, взнос на
  капитальный ремонт и управляющая организация дома - открытые данные АИС ППК
  «ФРТ» (Реформа ЖКХ): наборы «МКД в региональной программе капитального
  ремонта» по Москве, Санкт-Петербургу и Республике Татарстан и «Реестр
  управляющих организаций» от 01.09.2026, карточки домов на reformagkh.ru.
  Телефоны организаций приведены к виду +7XXXXXXXXXX: семизначному номеру
  добавлен код города (812, 843), нерабочие значения вроде «0» и «нет» пусты.
- Число подъездов - оценка по числу квартир и этажей, а не данные, у десяти
  домов, чьи карточки его не называют: Москва, Ленинский проспект 61/1 (это
  демо-дом); Санкт-Петербург, Гражданский проспект 9 корп. 2 литера А; Казань,
  проспект Победы 18/1, 45, 46А, 47, 56, 57А, 58, 90.
- Координаты домов - © участники OpenStreetMap, данные доступны по лицензии
  Open Database License (ODbL) 1.0: https://www.openstreetmap.org/copyright.
  Геокодирование - Nominatim.
- Организации из реестра в сиде не зарегистрированы, у них нет сотрудников и
  истории: для них верно «УК не подключена».
- Демо-организации, их сотрудники, жители, лицевые счета, начисления,
  показания, заявки, опросы, объявления, документы и список работ капитального
  ремонта демо-дома - модельные. Названия
  организаций начинаются с «Демо-УК», их ИНН не проходят контрольную сумму,
  картинки сгенерированы. Кадастровых номеров и номеров лицензий в сиде нет.
