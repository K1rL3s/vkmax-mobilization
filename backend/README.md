# Бэкенд Жэки Коммуналкина

FastAPI и бот на `maxo` в одном процессе, фоновые задачи на taskiq. Запуск всего решения в Docker описан в [README](../README.md#запуск), архитектура - в [docs/architecture.md](../docs/architecture.md).

## Запуск без Docker

Нужны Python 3.12, [uv](https://docs.astral.sh/uv/), [just](https://just.systems/), PostgreSQL и Redis: compose их порты на хост не публикует. `just` читает переменные из `../.env`, для запуска вне Docker там нужны `POSTGRES_HOST`, `REDIS_HOST` и `FILES_DIR`.

```sh
just sync       # зависимости
just migrate    # alembic upgrade head
just seed       # демо-данные в пустую базу
just api        # gunicorn: API и бот
just worker     # фоновые задачи и расписание
```

Проверки: `just check` (ruff, codespell, slotscheck, bandit, mypy), `just test` (pytest, базу поднимает testcontainers, нужен Docker). `just openapi` перезаписывает `../openapi.yaml` из кода, `just migration "<сообщение>"` создает миграцию.

## Демо-данные

`just seed` загружает в пустую базу справочник домов, организации из реестра и 17 демо-УК в Москве, Санкт-Петербурге и Казани с историей за полгода: пять открыты по демо-ссылкам, остальные видны на карте и в сравнении УК. Повторный запуск ничего не меняет. В Docker: `docker compose run --rm api python -m zheka.seed`, на развернутом боте - `/seed` в личке.

История кончается днем запуска, а дашборд и сравнение УК считают последние 30 дней, поэтому сид лучше запускать ближе к проверке. Заполнить базу заново можно только пересоздав ее, а это стирает квартиры и роли проверяющих.

Сид читает только `zheka/seed/data/` и в сеть не ходит; эти файлы один раз собрал `scripts/fetch_seed_data.py`:

- Дома (год постройки, этажность, площади, подъезды, взнос на капремонт, УК) - открытые данные Реформы ЖКХ: «МКД в региональной программе капитального ремонта» по Москве, Санкт-Петербургу и Татарстану, «Реестр управляющих организаций» от 01.09.2026 и карточки домов на reformagkh.ru. В каждом городе 12 улиц по 55 домов.
- Если карточка дома не назвала число подъездов или не открылась (часть закрыла капча), оно оценено по числу квартир и этажей, а УК у дома не указана.
- Кадастровый номер, износ, состояние и класс энергоэффективности - публичная карточка дома в ГИС ЖКХ, поиск по ФИАС GUID из выгрузки Реформы ЖКХ. УК и договор управления из ГИС ЖКХ сид не берет: демо-УК занимают только дома без УК.
- Координаты - © участники OpenStreetMap, ODbL 1.0 (https://www.openstreetmap.org/copyright), геокодирование через Nominatim, ненайденные адреса - через Overpass API.
- Организации из реестра не зарегистрированы, сотрудников и истории у них нет. Контакты - из реестра УК, заглушки вроде «Net@mail.ru» и «-» отброшены, телефоны приведены к +7XXXXXXXXXX.
- Демо-УК, их сотрудники, жители, лицевые счета, начисления, показания, заявки, опросы, объявления, документы и работы капремонта модельные. Названия начинаются с «Демо-УК», ИНН не проходят контрольную сумму, картинки сгенерированы, номеров лицензий нет.

Подробнее об источниках - в [docs/data.md](../docs/data.md).

## Yandex

Три необязательные переменные:

- `YANDEX_API_KEY` - API-ключ сервисного аккаунта Yandex Cloud, ему нужна роль `ai.languageModels.user` на каталог;
- `YANDEX_FOLDER_ID` - каталог этого аккаунта;
- `YANDEX_MODEL` - текстовая модель AI Studio, по умолчанию `yandexgpt-5-lite`.

С ними работают распознавание показаний по фото (Vision OCR), подсказка категории заявки (AI Studio) и расшифровка голосовых (SpeechKit). Без них распознавание отвечает пустым значением, подсказка - `category: null`, и житель выбирает категорию кнопками. Отвергнутый ключ (401 или 403) или ключ с символом не из ASCII выключает подсказки до перезапуска процесса.
