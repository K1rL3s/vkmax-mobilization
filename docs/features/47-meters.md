# Передача показаний счетчиков

Житель раз в месяц сам передает показания в мини-приложении: по фото, с расходом и предварительной суммой.

## Как работает

- «Моя квартира» -> «Показания» открыты подтвержденному собственнику или арендатору. Квартиры нет в данных УК - «Квартиры пока нет в данных УК» с кнопкой «Изменить номер квартиры». Неподтвержденному - «Сначала подтвердите квартиру» с кнопкой на подтверждение. Счетчиков нет - «Счётчиков пока нет»: их заводит УК.
- Виды: холодная и горячая вода, электричество, газ, отопление - по одному счетчику каждого вида. У двухтарифного электричества два поля, «День» и «Ночь».
- Под счетчиком «Поверка до ДД.ММ.ГГГГ», за 30 дней и меньше красным «осталось N дней» или «сегодня последний день» (напоминания - файл 50). После срока поверки подача по счетчику закрыта: «Срок поверки истёк - показания не примут, начисление пойдёт по нормативу. Поверку заказывают через УК».
- Месяц выбирается чипами, если открыто несколько периодов. Ни одного - «Окно подачи закрыто». Окно задает УК (по умолчанию 15-25 число), у дома без УК оно открыто всегда.
- Подсказка в поле - «Первое показание счётчика» или «Прошлое: ...». При повторной подаче за месяц «прошлым» считается показание предыдущего месяца, поэтому исправление опечатки вниз не выглядит ошибкой (файл 48).
- Фото обязательно, до 3 штук (пока его нет, над неактивной «Отправить показания» написано «Добавьте фото счётчика - без него показания не примут»), плитки «Снять» и «Из галереи» (файл 75). По первому фото число распознается и подставляется в поле, его можно поправить.
- После отправки - расход за месяц (у первого показания «Первое показание, расход пойдёт со следующего»), «К оплате ≈ ...» с пометкой «Предварительный расчёт, итог в квитанции» и сравнение со средним по дому. Если расход не меньше двух медиан прошлых показаний, появляется «Расход заметно выше обычного...» с кнопкой заявки.

## Как проверить

Перед началом: аккаунт А (`demo_resident_1`), подтвержденная квартира.

1. «Моя квартира» -> «Показания» - чипы видов счетчика, выберите холодную воду.
2. Добавьте фото кнопкой «Снять» или «Из галереи» - число распознается (без ключей Yandex поле останется пустым), при необходимости поправьте.
3. Отправьте - откроется результат с расходом, предварительной суммой и сравнением с домом.
4. Вернитесь в «Показания» и выберите тот же счетчик - подсказка «Прошлое: ...» покажет отправленное значение.

## Ограничения

- Отдельного экрана истории показаний у жителя нет.
- Если распознавание недоступно, поле просто остается пустым, без сообщения.
- Месяц, за который УК уже выставила квитанцию, пропадает из выбора без объяснения.
