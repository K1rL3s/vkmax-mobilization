# Неподключенные дома со спросом

Жители нажимают «Мне нужен» на доме без УК (файл 17). Этот спрос платформа показывает всем УК как повод подключить дом

## Как работает

- Раздел «Ждут подключения» внизу вкладки «Дома» в виде «Список», если такие дома есть
- До 50 домов по убыванию числа ждущих: видна первая десятка, «Показать все ещё N» раскрывает остальные
- Строка: адрес и «1 ждёт», «2 ждут» - сколько жителей нажали «Мне нужен». Подключенный дом из списка пропадает

## Как проверить

Перед началом: аккаунт А после файла 17 нажал «Мне нужен» на доме без УК (если нет - нажмите сейчас на любом неподключенном доме на карте)

1. Аккаунт Б (`demo_admin_1` или `demo_staff_1`) -> «Дома» -> «Список» - внизу «Ждут подключения»
2. В списке дом из файла 17 с адресом и числом ждущих
3. Если домов больше десяти, «Показать все ещё N» раскроет список

## Ограничения

- Список общий для всей платформы, а не только для района вашей УК
