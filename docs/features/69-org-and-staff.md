# Организация и сотрудники

Один экран кабинета УК: карточка УК, контакты для жителей, окно подачи показаний, порог склейки заявок, приглашения в команду и роли.

## Как работает

- Открывается по названию УК под заголовком «Дома» или строкой «Организация и сотрудники» в списке домов. Карточку (ИНН, лицензия, адрес, число домов и сотрудников, дата в сервисе, роль) и команду видят создатель и администратор, сотруднику настройки доступны только для чтения.
- Настройки: «Окно подачи показаний» («Принимать весь месяц» или «С какого числа» / «По какое число», 1-28), «Коллективные заявки» («Сколько квартир», 2-100, и «За сколько часов», 1-168), «Контакты для жителей» (телефон обязателен, аварийный телефон, почта, сайт, часы приема) - их житель видит в карточке дома. «Сохранить настройки» активна, когда есть изменения и поля заполнены верно.
- Роли: создатель, администратор, сотрудник, исполнитель. Создатель приглашает и исключает всех, кроме создателя (он один); администратор - только сотрудников и исполнителей; остальные не могут. Создателя исключить нельзя.
- Приглашение - ссылка бота со сроком (1 день / 3 дня / неделя / 30 дней) и числом активаций (1, 3, 5, 10). Истекшая, исчерпанная или отозванная ссылка не работает, вошедшие по ней остаются. Тому, кто уже в команде, ссылка с более высокой ролью повышает роль.
- Демо-УК общая для всех проверяющих, поэтому настройки и команда только для чтения: поля неактивны, под кнопкой «В демо-УК настройки общие для всех проверяющих и не меняются», исключения нет. Приглашения создавать можно, отзывать - только свои.

## Как проверить

Перед началом: аккаунт Б, администратор демо-УК (`demo_admin_1`).

1. Кабинет УК -> «Дома» -> название УК под заголовком - карточка: ИНН, адрес, число домов и сотрудников, «Ваша роль» с плашкой «Администратор».
2. Ниже поля настроек неактивны, «Сохранить настройки» не нажимается, под ней «В демо-УК настройки общие для всех проверяющих и не меняются».
3. В блоке «Команда»: «Приглашения» -> «Пригласить в команду», роль «Сотрудник», срок «3 дня», активаций «1» -> «Создать ссылку» - откроется «Ссылка готова» с кнопками «Скопировать» и «Поделиться».
4. Новая ссылка в группе «Действуют»; откройте ее, «Отозвать» -> подтвердите - статус «Отозвано», ссылка в «Больше не действуют».
5. Под списком команды «В демо-УК команда общая для всех проверяющих, исключить никого нельзя». Отзыв чужой ссылки дает «Демо-УК общая для всех проверяющих, это действие в ней отключено».
6. Тем же аккаунтом откройте `demo_staff_1` и «Организация и сотрудники» - вместо карточки пояснение, что ее видят только создатель и администраторы, блока «Команда» нет.

## Ограничения

- Сохранить настройки или исключить сотрудника проверяющий не может ни в одной УК: свою УК без кода регистрации (файл 68) он не заведет.
