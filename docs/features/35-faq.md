# Раздел «Как это работает»

Статичный FAQ отвечает на частые вопросы о сервисе по темам, чтобы житель
не писал диспетчеру то, что уже написано в приложении.

## Как работает

- Открывается из профиля: блок «Помощь» -> ячейка «Как это работает».
- Семь разделов по порядку: «Дом и квартира», «Заявки», «Ваши права» (15
  вопросов, см. `34-rights-answers.md`), «Счетчики и начисления», «Опросы»,
  «Прием и доступ в квартиру», «Бот в MAX» - 34 вопроса всего.
- Каждый вопрос раскрывается нажатием; тексты ответов зашиты во фронтенд и
  не запрашиваются с сервера.
- Поиска или фильтра по вопросам нет, только список по разделам сверху вниз.
- Внизу карточка «Не нашли ответ?» со ссылкой на карточку дома.

## Как проверить

Перед началом: аккаунт А, дом подключен.

1. Профиль -> «Помощь» -> «Как это работает» - открывается список из семи
   разделов.
2. В разделе «Заявки» раскройте любой вопрос - виден текст ответа.
3. Прокрутите до конца - карточка «Не нашли ответ?» ведет в карточку дома.

## Ограничения

- Текст статичный: чтобы его изменить, нужен новый релиз фронтенда.
- Раздел «Ваши права» отвечает только по нормам, которые сверены с текстом
  акта; остальные разделы - общие пояснения без ссылок на пункты закона.
