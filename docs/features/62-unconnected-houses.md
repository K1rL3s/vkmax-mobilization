# Неподключенные дома со спросом

Жители могут нажать «Мне нужен» на доме без УК (см. 16-not-connected-house.md) - это спрос, который платформа собирает и показывает всем УК как повод подключить дом.

## Как работает

- Раздел «Ждут подключения» внизу вкладки «Дома» кабинета УК в виде «Список», без подписи. Показывается, только если такие дома есть.
- В списке до 50 домов с наибольшим числом ждущих, по убыванию. Видна первая десятка, кнопка «Показать все ещё N» раскрывает остальные.
- Строка дома: адрес и «1 ждёт», «2 ждут», «5 ждут» - число нажавших «Мне нужен» жителей этого дома. Житель нажимает «Мне нужен» на доме один раз; как только дом подключается к УК, он пропадает из списка.

## Как проверить

Перед началом: аккаунт А после шага 16 (нажали «Мне нужен» на доме без УК); если список пуст, откройте любой неподключенный дом на карте и нажмите «Мне нужен» тем же аккаунтом перед этим шагом.

1. Аккаунт Б (`demo_admin_1` или `demo_staff_1`) -> «Дома» -> «Список» - внизу раздел «Ждут подключения».
2. Найдите в списке дом из шага 16 (или любой другой) - строка с адресом и числом ждущих («N ждут»).
3. Если домов больше десяти, нажмите «Показать все ещё N» - список раскроется полностью.

## Ограничения

- Список не привязан к вашей организации: он покажет неподключенные дома со всей платформы, а не только рядом с домами вашей УК.
