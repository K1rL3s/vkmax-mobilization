# Вопрос по строке квитанции

Житель задает вопрос по одной строке квитанции, не пересказывая цифры. УК получает заявку, где уже есть услуга, период, сумма, расчет и изменение к прошлому месяцу.

## Как работает

- На экране квитанции в блоке «Построчно» под каждой строкой кнопка «Вопрос по строке». Она открывает форму с заголовком «Вопрос по строке «Горячая вода» за сентябрь 2026», житель пишет свой вопрос.
- Описание заявки собирается само: «По строке «Горячая вода» за 09.2026: 474.60 руб. (3,5 м³ × 135.60 руб.), к прошлому месяцу +70.00 руб.», затем вопрос жителя и «Прошу сообщить состав начисления и данные, использованные при расчете».
- Создается заявка «Спор по начислению» со сроком 10 рабочих дней. Если показания за период сдавали с фото, фото прикладываются к заявке.
- «Оспорить начисление» по квитанции целиком тоже доступно (файл 52).

## Как проверить

Перед началом: аккаунт А (`demo_resident_1`), подтвержденный собственник с историей начислений.

1. «Моя квартира» -> «Начисления» -> любой месяц.
2. У строки «Горячая вода» нажмите «Вопрос по строке», напишите «Почему выросло?», отправьте.
3. Откроется созданная заявка с цифрами в описании, в кабинете УК она есть в списке заявок. Фото показаний у демо-квартиры нет.

## Ограничения

- Расчет в скобках есть только у строк с объемом и тарифом (вода, электроэнергия), у строк по площади - только сумма.
- Если прошлого месяца нет, изменение не пишется; если строки в прошлом месяце не было - «новая строка в этом месяце».
