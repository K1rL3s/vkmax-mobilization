# Настройки уведомлений

Житель для каждой категории уведомлений выбирает: со звуком, без звука или выключено. Мешающий вид сообщений можно заглушить, не отключая бота целиком

## Как работает

- Профиль -> «Уведомления и звук»: четыре категории - «Заявки», «Объявления УК», «Счётчики и поверка», «Недельная сводка» (файл 66). У каждой три варианта: «Со звуком», «Без звука», «Выключены»
- Выбор сохраняется сразу и меняет только свою категорию. Ошибка - «Не получилось сохранить настройку. Проверьте связь и выберите ещё раз»
- По умолчанию первые три категории без звука, «Недельная сводка» выключена
- Внизу: «Статусы ваших заявок, приёмка работ, записи на приём и запросы доступа в квартиру приходят всегда». Их можно только сделать беззвучными

## Как проверить

Перед началом: аккаунт А с привязанным домом

1. «Профиль» -> «Уведомления и звук» - четыре категории, у каждой отмечен текущий уровень
2. В «Заявках» выберите «Выключены» - выбор применится сразу
3. Выйдите в профиль и откройте экран снова - изменилась только «Заявки», остальные на прежнем уровне
4. Подайте заявку или дождитесь смены ее статуса - уведомление о статусе все равно придет
5. Верните «Заявки» на «Без звука»
