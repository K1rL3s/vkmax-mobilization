# Демо-доступ по ссылке

Вход в MAX не подменить демо-логином, поэтому роль в демо-УК выдает ссылка с параметром `start`: квартира или роль сотрудника за один переход.

## Как работает

- `demo_resident_N` дает подтвержденную квартиру в первом доме демо-УК №N с начислениями за полгода, `demo_staff_N` и `demo_admin_N` - роль сотрудника или администратора. N от 1 до 5, №5 закреплена за проверкой API. Ссылка на роль выше текущей повышает ее, на роль ниже - ничего не меняет.
- `demo_executor_N` меняет роль в этой УК на исполнителя: бот назначает на вас последнюю новую или принятую заявку демо-квартиры этого N и присылает карточку исполнителя. Без такой заявки просит сначала пройти по `demo_resident_N`. Роль сотрудника возвращает `demo_staff_N` или `demo_admin_N`.
- `/seed` заполняет пустую базу: «⏳ Заполняю демо-данные, это займет до минуты», затем «✅ Демо-данные готовы» или «👌 Демо-данные уже есть, ничего не менял».
- `/demo` сразу присылает по одному напоминанию каждого вида с рабочей кнопкой (показания, поверка, опрос, запись на прием), даже при выключенных уведомлениях.

## Как проверить

Перед началом: аккаунт А, согласие дано (файл 01), дома еще нет.

1. Откройте демо-ссылку жителя для N=1 - «🎟 Демо-доступ открыт: ваша квартира ...» и кнопка «📱 Открыть приложение».
2. В приложении подайте заявку любой категории с коротким описанием (форма разобрана в файле 19).
3. Тем же аккаунтом откройте демо-ссылку исполнителя для N=1 - «🎟 Демо-доступ открыт: вы исполнитель ...», следом карточка исполнителя.
4. Откройте демо-ссылку сотрудника для N=1 - роль вернется к сотруднику, придет сообщение с кнопкой «🧑‍💼 Открыть кабинет УК».
5. Отправьте боту `/demo` - придет по одному напоминанию каждого вида.

## Ограничения

- Пока вы исполнитель, кабинет УК этой организации недоступен.
- Демо-УК №5 закрыта для ролей исполнителя и администратора.
- `/seed` и `/demo` не показаны в меню команд бота.
