# Демо-доступ по ссылке

Вход в MAX не подменить демо-логином, поэтому роль в демо-УК выдает ссылка с
параметром `start`: квартира или роль сотрудника за один переход, без ручной
настройки.

## Как работает

- `demo_resident_N` дает подтвержденную квартиру в первом доме демо-УК №N с
  начислениями за полгода; `demo_staff_N` и `demo_admin_N` - роль сотрудника
  или администратора. N от 1 до 5, №5 закреплена за проверкой API. Ссылка на
  роль выше текущей повышает ее, на роль ниже - ничего не меняет.
- `demo_executor_N` заменяет роль сотрудника/администратора в этой УК на
  исполнителя: бот выбирает последнюю новую или принятую заявку
  демо-квартиры этого N, назначает ее на вас и присылает карточку
  исполнителя; без такой заявки просит сначала пройти по `demo_resident_N`.
  Роль сотрудника возвращает ссылка `demo_staff_N`/`demo_admin_N` или
  демо-вход в приложении. Если MAX открывает ссылку сразу в мини-приложении,
  тот же доступ выдает `POST /api/demo/activate`.
- `/seed` заполняет пустую базу: «⏳ Заполняю демо-данные, это займет до
  минуты», затем «✅ Демо-данные готовы» или «👌 Демо-данные уже есть, ничего
  не менял».
- `/demo` сразу присылает вызвавшему по одному напоминанию каждого вида с
  рабочей кнопкой (показания, поверка, опрос, запись на прием), даже при
  выключенных уведомлениях.

## Как проверить

Перед началом: аккаунт А, согласие уже дано (после файла 01), дома еще нет.

1. Откройте демо-ссылку жителя для N=1 - «🎟 Демо-доступ открыт: ваша
   квартира ...» и кнопка «📱 Открыть приложение».
2. В приложении подайте заявку любой категории с коротким описанием - форму
   разбирает блок 4, здесь нужна только сама заявка.
3. Тем же аккаунтом откройте демо-ссылку исполнителя для N=1 - «🎟
   Демо-доступ открыт: вы исполнитель ...», следом - карточка исполнителя.
4. Откройте демо-ссылку сотрудника для N=1 - роль вернется к сотруднику,
   придет уведомление с кнопкой «🧑‍💼 Открыть кабинет УК».
5. Отправьте боту `/demo` - придет по одному напоминанию каждого вида.

## Ограничения

- Пока вы исполнитель, кабинет УК этой организации недоступен; демо-УК №5
  закрыта для роли исполнителя и администратора, а `/seed` и `/demo` не
  показаны в меню команд бота.
