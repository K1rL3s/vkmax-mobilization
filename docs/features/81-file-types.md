# Тип файла по содержимому

Фото и видео к заявкам, показаниям и возврату работы сервер сохраняет и отдает другим людям, поэтому верить заголовку `Content-Type` от клиента нельзя. Сервер сам определяет тип по первым байтам файла. Житель и УК ничего нового не видят, пока файл настоящий: фото и видео грузятся как раньше.

## Как работает

- Загрузка идет через `POST /api/files`: форма заявки (кнопка «Добавить» под вложениями), показания счетчика, возврат работы с приемки. Фото и видео, отправленные боту в «📝 Подать заявку», сервер проверяет так же.
- Разрешены JPEG, PNG, WEBP, HEIC, MP4 и MOV, тип определяется по сигнатуре. Файл, у которого в начале нет ни одной из них, отклоняется с 400 «Поддерживаются только изображения и видео MP4 или MOV», даже если клиент назвал его картинкой, и на диске ничего не остается. Фото, отправленное под видом видео или наоборот, тоже отклоняется.
- Фото больше 10 МБ - 400 «Файл больше 10 МБ».
- Ссылка на файл (`/files/...`) приходит с заголовком `X-Content-Type-Options: nosniff`, поэтому браузер не угадывает тип заново.

## Как проверить

Перед началом: тестовый токен и команды из README «Проверка API».

1. В мини-приложении (`demo_resident_1`) в новую заявку приложите скриншот PNG и отправьте - заявка создается, фото открывается в карточке заявки и у УК (`demo_staff_1`, вкладка «Заявки»).
2. Отправьте текстовый файл под видом картинки:
   ```sh
   curl -H "Authorization: Bearer $TOKEN" -F "file=@README.md;type=image/jpeg" \
     https://vkmax.k1rles.ru/api/files
   ```
   Ответ 400 «Поддерживаются только изображения и видео MP4 или MOV».
3. Загрузите тем же способом настоящее фото и выполните `curl -I` по подписанной ссылке из ответа - в заголовках есть `X-Content-Type-Options: nosniff`.

## Ограничения

- Сервер сверяет только сигнатуру и не декодирует изображение, поэтому файл с настоящим заголовком JPEG и чем угодно дальше пройдет.
- AVIF и старые MOV без атома `ftyp` отклоняются.
- Фото из бота в формате WEBP сохраняются как `.webp`, и распознавание показаний (Yandex Vision) их не читает.
