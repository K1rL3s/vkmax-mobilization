# QR-коды на лифте, свете и уборке

Житель у сломанного лифта сканирует наклейку в кабине, и мини-приложение сразу открывает заявку «Лифт» с подъездом в описании

## Как работает

- Кабинет УК -> «Дома» -> дом -> «QR-коды дома», переключатель «Подъезды / Лифты / Свет / Уборка». Коды объектов печатаются по листу A4 на подъезд с подписью вроде «Сломался лифт? Наведите камеру, заявка откроется в MAX»
- Если житель уже живет в доме, приложение выбирает это проживание. Если нет - привязывает дом так же, как подъездный QR: житель становится неподтвержденным жителем дома
- Открывается форма заявки с выбранной категорией, описанием «Подъезд N: » и панелью похожих заявок соседей
- Если УК дома не подключена, заявку отправить нельзя

## Как проверить

Перед началом: аккаунт Б (`demo_admin_1`)

1. Кабинет УК -> «Дома» -> первый дом -> «QR-коды дома» -> «Лифты» - печатная форма с QR-кодом на каждый подъезд
2. Отсканируйте код камерой телефона с MAX (или откройте его ссылку) - откроется форма заявки «Лифт» с текстом «Подъезд 1: »

## Ограничения

- Переход из камеры телефона на живых Android и iOS не проверен
- Подъезд попадает только в текст описания
- Любой, кто отсканировал код, например гость в лифте, становится неподтвержденным жителем дома
- Коды лифтов печатаются для каждого подъезда, даже если лифта в доме нет
