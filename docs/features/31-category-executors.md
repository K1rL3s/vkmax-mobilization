# Исполнители по категориям

УК один раз закрепляет категорию заявок за исполнителем, и новые заявки этой категории уходят ему без ручного назначения.

## Как работает

- Блок «Исполнители по категориям» в настройках организации: строка на каждую из 11 категорий. Нажатие открывает шторку с «Не назначен» и всеми исполнителями организации.
- Новая, повторная и телефонная заявка категории сразу назначается закрепленному исполнителю. После его отказа (файл 33) назначение по категории не повторяется, дальше заявку переназначает диспетчер.
- Если исполнителя исключили из организации или сменили ему роль, категория возвращается к «Не назначен».
- Менять выбор могут создатель и администраторы. Сотрудник видит строки без стрелки и подсказку «Исполнителей по категориям назначают создатель и администраторы организации».
- В демо-УК блок только для чтения даже у администратора: под ним подсказка «В демо-УК настройки общие для всех проверяющих и не меняются».

## Как проверить

Перед началом: аккаунт Б, `demo_admin_1`.

1. «Дома» -> «Организация и сотрудники» -> «Исполнители по категориям» - список из 11 категорий.
2. Нажмите строку «Лифт» - ничего не откроется, строки без стрелки, под блоком «В демо-УК настройки общие для всех проверяющих и не меняются».

## Ограничения

- Закрепление действует только на заявки, созданные после него.
- В демо-УК назначение по категории не проверить, оно работает в УК, зарегистрированной по коду (файл 68). В демо исполнителя назначает ссылка `demo_executor_1` (файл 32).
