# Раздел «Как это работает»

FAQ для жителя: ответы на частые вопросы о сервисе, разложенные по темам.

## Как работает

- Открывается из профиля: блок «Помощь» -> «Как это работает».
- Семь разделов по порядку: «Дом и квартира», «Заявки», «Ваши права» (17 вопросов, файл 39), «Счетчики и начисления», «Опросы», «Прием и доступ в квартиру», «Бот в MAX» - 37 вопросов. В «Заявках» есть вопрос «Как узнать, сообщили ли соседи?» про доску «Проблемы дома» (файл 45).
- Вопрос раскрывается нажатием. Поиска и фильтра нет.
- Внизу карточка «Не нашли ответ?» с кнопкой в карточку дома.
- В разделе «Бот в MAX» ответ «Что умеет бот?» называет команды `/help` и `/faq`: в боте они присылают обзор возможностей и короткий FAQ (файл 01).

## Как проверить

Перед началом: аккаунт А, дом подключен.

1. Профиль -> «Помощь» -> «Как это работает» - список из семи разделов.
2. В разделе «Заявки» раскройте любой вопрос - виден ответ.
3. Прокрутите до конца - карточка «Не нашли ответ?» ведет в карточку дома.

## Ограничения

- Ссылки на пункты закона есть только в разделе «Ваши права», остальные разделы - общие пояснения.
