# Реестр уведомлений по объявлению и опросу

Отчет о доставке (файл 57) говорит, сколько сообщений дошло, но не каким квартирам. Реестр показывает администратору УК, каким квартирам MAX доставил объявление в личные сообщения и когда, и каких квартир в сервисе нет: по этому списку квартиры без отметки уведомляют другим способом.

## Как работает

- У объявления с каналом «Личные сообщения» на вкладке «Объявления» есть кнопка «Реестр уведомлений». Вверху экрана строка «Доставлено квартирам N из M, без отметки K», ниже таблица «Кв. / Подъезд / Статус / Время».
- Статусы: «Доставлено», «Выключил объявления», «Бот остановлен», «MAX не доставил», «Нет в сервисе»; пока рассылка идет - «Отправляется…». Под статусом указано «собственник/арендатор, подтверждён/не подтверждён», имен нет.
- Переключатель «Только без отметки» оставляет в таблице квартиры для бумажного уведомления. «Распечатать» отдает лист A4 с подписью «Реестр фиксирует доставку сообщения в MAX, прочтение MAX не сообщает. Квартиры без отметки нужно уведомить другим способом». У демо-УК на листе пометка «ДЕМО».
- «Получить PDF в чат с ботом» через несколько секунд присылает в диалог с ботом файл `reestr-N.pdf` с подписью «📄 Реестр уведомлений по объявлению от ДД.ММ.ГГГГ» и адресом дома. В файле то же, что на экране: дом и УК, текст объявления, «Доставлено квартирам N из M, без отметки K», строка про чат дома, таблица «Кв. / Подъезд / Житель / Статус / Время» и подпись, что реестр фиксирует доставку в MAX и не заменяет заказное письмо. Выбранный дом и «Только без отметки» попадают в PDF. На демо-УК на каждой странице пометка «ДЕМО».
- Опрос: переключатель «Сообщить жителям в личку» при создании рассылает «🗳 Новый опрос «...», голосование до ДД.ММ.ГГГГ» с кнопкой «🗳 Проголосовать», а на странице опроса в кабинете появляется своя кнопка «Реестр уведомлений».
- Реестр видит только администратор УК: у `demo_staff_1` кнопки нет, сотрудник чужой УК получает 404.

## Как проверить

Перед началом: аккаунт Б после `demo_admin_1`, кнопка «🧑‍💼 Открыть кабинет УК».

1. «Объявления» -> у засеянного объявления с «Личные сообщения» нажмите «Реестр уведомлений» - строка «Доставлено квартирам N из M, без отметки K» и таблица «Кв. / Подъезд / Статус / Время» с разными статусами.
2. Включите «Только без отметки» - в таблице останутся квартиры без «Доставлено». Нажмите «Распечатать» - лист A4 с подписью про доставку в MAX и пометкой «ДЕМО».
3. Нажмите «Получить PDF в чат с ботом» - кнопка сменится на «Отправили в чат с ботом», через несколько секунд в бот придет `reestr-N.pdf` с подписью «📄 Реестр уведомлений по объявлению от ...» и адресом дома.
4. «Новое объявление» -> первый дом -> «Личные сообщения» -> «Отправить» -> «Отправить», затем «Реестр уведомлений» у нового объявления - в строке вашей квартиры `Д...` сначала «Отправляется…», через несколько секунд «Доставлено» со временем, а в бот приходит само объявление.
5. «Опросы» -> «Новый опрос», включите «Сообщить жителям в личку» -> «Создать опрос» - в бот придет «🗳 Новый опрос ...» с кнопкой «🗳 Проголосовать», на странице опроса в кабинете - кнопка «Реестр уведомлений».

## Ограничения

- «Доставлено» значит, что MAX принял сообщение, а не что его прочитали. Реестр не заменяет заказное письмо о собрании.
- В демо-УК личное сообщение получает только автор, поэтому квартиры других проверяющих показаны как «Нет в сервисе». У объявлений, отправленных до появления реестра, отметок нет.
- Печать в MAX на телефоне не проверена, поэтому есть PDF в чат. Скачивания прямо в мини-приложении нет. Если бот не может написать администратору, под кнопкой появится «Бот не может вам написать: откройте чат с ботом, запустите его и повторите».
