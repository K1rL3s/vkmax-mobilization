# Реестр уведомлений по объявлению и опросу

Реестр показывает администратору УК, каким квартирам MAX доставил объявление или приглашение к опросу и когда, а каких квартир в сервисе нет: их уведомляют другим способом.

## Как работает

- У объявления с каналом «Личные сообщения» кнопка «Реестр уведомлений». Вверху «Доставлено квартирам N из M, без отметки K», ниже таблица «Кв. / Подъезд / Статус / Время».
- Статусы: «Доставлено», «Выключил объявления», «Бот остановлен», «MAX не доставил», «Нет в сервисе», во время рассылки - «Отправляется…». Под статусом «собственник/арендатор, подтверждён/не подтверждён», имен нет.
- «Только без отметки» оставляет квартиры для бумажного уведомления. «Распечатать» дает лист A4 с подписью «Реестр фиксирует доставку сообщения в MAX, прочтение MAX не сообщает. Квартиры без отметки нужно уведомить другим способом». У демо-УК на листе пометка «ДЕМО».
- «Получить PDF в чат с ботом» через несколько секунд присылает в бота `reestr-N.pdf` с подписью «📄 Реестр уведомлений по объявлению от ДД.ММ.ГГГГ» и адресом дома. В PDF то же, что на экране, с учетом «Только без отметки», плюс текст объявления и строка про чат дома.
- Опрос: переключатель «Сообщить жителям в личку» рассылает «🗳 Новый опрос «...», голосование до ДД.ММ.ГГГГ» с кнопкой «🗳 Проголосовать», и у опроса в кабинете появляется своя кнопка «Реестр уведомлений».
- Реестр видит только администратор УК.

## Как проверить

Перед началом: аккаунт Б через ссылку `demo_admin_1`, кнопка «🧑‍💼 Открыть кабинет УК».

1. «Объявления» -> у засеянного объявления с «Личные сообщения» нажмите «Реестр уведомлений» - строка «Доставлено квартирам N из M, без отметки K» и таблица с разными статусами.
2. Включите «Только без отметки» - останутся квартиры без «Доставлено». «Распечатать» - лист A4 с подписью про доставку в MAX и пометкой «ДЕМО».
3. «Получить PDF в чат с ботом» - кнопка сменится на «Отправили в чат с ботом», через несколько секунд в бот придет `reestr-N.pdf`.
4. «Новое объявление» -> первый дом -> «Личные сообщения» -> «Отправить» -> «Отправить», затем «Реестр уведомлений» у нового объявления - в строке вашей квартиры сначала «Отправляется…», потом «Доставлено» со временем.
5. «Опросы» -> «Новый опрос», включите «Сообщить жителям в личку» -> «Создать опрос» - в бот придет «🗳 Новый опрос ...» с кнопкой «🗳 Проголосовать», у опроса в кабинете - «Реестр уведомлений».

## Ограничения

- «Доставлено» не значит «прочитано». Реестр не заменяет заказное письмо о собрании.
- В демо-УК личное сообщение получает только автор, поэтому квартиры других проверяющих показаны как «Нет в сервисе».
- Скачать PDF прямо в мини-приложении нельзя, только получить в чат с ботом. Если бот не может написать администратору, под кнопкой «Бот не может вам написать: откройте чат с ботом, запустите его и повторите».
