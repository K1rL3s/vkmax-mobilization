# Контроль сроков

Срок заявки теперь не просто цифра в карточке. Сотрудник УК узнает о нем
заранее, а житель получает сообщение, когда срок прошел, и сразу видит, куда
жаловаться.

Как работает:

- Раз в 5 минут бот проверяет открытые заявки. За четверть срока, но не раньше
  чем за сутки и не позже чем за час, сотрудникам УК и исполнителю приходит
  «⏳ Заявке №... осталось N ч». У протечки со сроком 3 суток это 18 часов.
- Когда срок истек, сотрудники и исполнитель получают «🔴 Заявка ...
  просрочена» с адресом. Житель получает сообщение с нормой права и кнопкой
  «📄 Жалоба в ГЖИ», она открывает карточку заявки с готовым текстом.
  Председатель дома узнает о просрочке без данных автора.
- Каждое сообщение уходит один раз. Если бот простаивал и срок уже прошел,
  приходит только сообщение о просрочке, без запоздалого предупреждения.
- Заявку на приемке не трогают: работа сдана, ход за жителем.

Где посмотреть в демо: войдите по ссылке `demo_resident_1`, подайте заявку и
в блоке «Срок» нажмите «⏩ Демо: срок истек». Через пару секунд бот пришлет
сообщение о просрочке, а карточка покажет текст для ГЖИ. Кнопка есть только
в демо-УК, только у автора и только у открытой заявки, срок которой еще идет.

Ограничения: председатель получает сообщение о каждой просрочке, сводки раз
в день нет. Заявки, просроченные до включения контроля, уведомлений не получат.
