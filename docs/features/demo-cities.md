# Демо-УК в трех городах

Демо-данные теперь покрывают Москву, Санкт-Петербург и Казань, чтобы карта и сравнение УК были плотными.

- Пять демо-УК открываются по демо-ссылкам, у каждой 12 домов в одном городе, собранных в компактный район.
- Еще 12 фоновых демо-УК войти не дают: они видны на карте и в сравнении с другими УК.
- У каждой из пяти демо-УК с доступом на карте есть дом с аварией, с эскалацией, с просроченной заявкой, с открытыми заявками и спокойный, а еще свежее срочное объявление, идущий опрос, записи на прием на месяц вперед и заявки на подтверждение квартир.
- Во всех демо-домах есть показания счетчиков за текущий месяц, у каждого дома своя доля сдавших.
- Все организации и их данные вымышлены, адреса домов настоящие.
