# Обратный сбор доступа в квартиры

Замена стояка или поверка разом в десяти квартирах обычно значит десять звонков и бумажки на дверях. УК один раз описывает, когда придет, а квартиры сами выбирают удобное окно.

## Как работает

- Создать сбор может только админ или создатель организации: «Прием» -> «Сбор доступа» -> «Собрать доступ». Сотруднику вместо формы - «Собрать доступ может администратор».
- Форма: дом (если их несколько), причина, день - текстовое поле с маской ДД.ММ.ГГГГ, а не системный календарь, день не может быть в прошлом; время с-до, длина окна в минутах и число квартир на окно - по ним строится список окон; квартиры выбираются поиском по номеру или жителю, в списке сразу только квартиры с подтвержденным жителем. Отправка требует подтверждения: «Жители N квартир получат уведомление. Отменить сбор и поменять окна потом нельзя».
- Каждая подтвержденная целевая квартира получает одно сообщение с окнами доступа. В приложении это карточка «Доступ в квартиру» в списке записей: причина, дата, кнопка на каждое свободное окно «с ЧЧ:ММ»; выбранное окно подсвечено, занятые чужие окна тускнеют, сменить выбор можно, пока в новом окне есть место. Неподтвержденному жителю кнопок нет, только «Подтвердить квартиру».
- В боте та же карточка: «🔑 УК просит доступ в квартиру {дата}\n{адрес}\n\n{причина}\n\n🕐 Выберите удобное время», кнопка на каждое окно «🕐 ЧЧ:ММ», выбранное - «✅ ЧЧ:ММ - выбрано»; нажатие правит то же сообщение.
- У сотрудника - живая сетка по окнам: «свободно N из M» или «мест нет» и квартиры под каждым, «Не ответили» отдельным блоком (напоминания из кабинета нет, договариваться приходится самим), в списке сборов у каждого - «ответили N из M».

## Как проверить

Перед началом: аккаунт Б после шага 52 (`demo_admin_1`); аккаунт А (`demo_resident_1`) - подтвержденный житель.

1. «Прием» -> «Сбор доступа» -> «Собрать доступ»: впишите причину, дату (ДД.ММ.ГГГГ), время и длину окна, отметьте квартиру аккаунта А -> «Собрать доступ» -> подтвердите в листе.
2. Аккаунт А -> «Мои записи» -> карточка «Доступ в квартиру» -> нажмите свободное окно - кнопка подсветится как выбранная.
3. Аккаунт Б -> откройте этот сбор: в сетке у выбранного окна появится квартира аккаунта А, строка сбора в списке показывает «ответили 1 из 1».

## Ограничения

- После отправки сбор нельзя ни отменить, ни изменить окна или список квартир.
