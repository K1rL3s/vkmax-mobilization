# Заявка по телефонному звонку

Жителя, который звонит по телефону, сотрудник УК заводит заявкой сам, и дальше она идет как заявка из приложения.

## Как работает

- Кнопка «Заявка по звонку» во вкладке «Заявки» кабинета УК открывает форму.
- «Что случилось»: дом (поиск по улице и номеру), категория, «В квартире» / «В доме», если категория не задает место сама (файл 19), «Описание проблемы».
- «Кто позвонил»: квартира и житель дома либо «Имя звонившего» и «Телефон звонившего». Выбранный житель получает уведомления в MAX и принимает работу. Без жителя нужен телефон: «Без квартиры или жителя нужен телефон звонившего».
- «Создать заявку» открывает карточку новой заявки, в поле «Как поступила» - «Телефон». Дальше срок, статусы и исполнитель работают как у обычной заявки.

## Как проверить

Перед началом: аккаунт Б, `demo_staff_1`.

1. Вкладка «Заявки» -> «Заявка по звонку» - открывается форма.
2. Выберите дом, категорию «🗑 Мусор», опишите проблему, например «Не вывезли мусор, баки переполнены третий день».
3. В «Кто позвонил» не выбирайте квартиру, впишите имя и телефон звонившего.
4. Нажмите «Создать заявку» - откроется карточка заявки с каналом «Телефон» и без привязанного жителя.

## Ограничения

- Без выбранного жителя заявка никого не уведомляет в MAX: статус меняется только в кабинете УК.
