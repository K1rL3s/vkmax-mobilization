# Карточка дома

Карточка дома - паспорт с публичными данными: год постройки, УК, тарифы,
капремонт и документы. Часть сведений жилец видит без запроса, как требует
ПП РФ 416.

## Как работает

- Открывается из «Профиль» -> «Карточка дома» и с плавающей «?» -> раздел FAQ.
- Сверху вниз: адрес, «Отключения» (если сейчас есть, файл 12), мини-карта
  «Соседние дома на карте» (файл 06), факты (подъездов - всегда, год
  постройки, этажность и площадь - если известны), раздел «Управляющая
  компания» (контакты - файл 14, показатели - файл 15, ячейка «Аварийная
  служба»), «Тарифы ЖКУ», «Капремонт» и «Документы».
- «Аварийная служба»: если у УК указан номер, заголовок ячейки - сам номер,
  нажатие сразу звонит; если нет - «Что делать при аварии?» с подсказкой про
  квитанцию и доску объявлений, нажатие открывает экран «Авария» (файл 17).
- «Тарифы ЖКУ» показывает только действующую сейчас цену по каждой услуге
  (ХВС, ГВС, электричество, содержание, взнос на капремонт) с датой «с ...»;
  прежние цены не видны.
- «Капремонт»: название региональной программы, затем «Ближайшие» и
  «Выполненные» работы с годом. «Документы» - список файлов-заглушек, каждый
  открывает подписанную ссылку; внизу - подпись про модельные данные.

## Как проверить

Перед началом: аккаунт А на демо-квартире (после файла 12).

1. Откройте «Профиль» -> «Карточка дома» - адрес вверху, ниже, если есть, -
   «Отключения» и мини-карта «Соседние дома на карте».
2. Ниже - факты о доме: «Подъездов» видно всегда, «Построен», «Этажей» и
   «Площадь» - если они известны.
3. В разделе «Управляющая компания» найдите «Аварийная служба»: если номер
   указан - ячейка сразу звонит, если нет - заголовок «Что делать при
   аварии?» и подсказка про квитанцию, нажатие ведет на экран «Авария».
4. Откройте «Тарифы ЖКУ» - строки по каждой услуге с ценой и датой действия.
5. Откройте «Капремонт» - программа, затем «Ближайшие» и «Выполненные»
   работы с годом.
6. Откройте «Документы» - несколько строк-заглушек, каждая открывает файл по
   ссылке; внизу - подпись про модельные данные.

## Ограничения

- Документы - сгенерированные заглушки с именами файлов вместо человеческих
  названий: загрузки настоящих документов в кабинете УК пока нет.
