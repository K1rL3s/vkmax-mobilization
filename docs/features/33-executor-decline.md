# Отказ исполнителя и «кто сейчас действует»

Исполнитель, который не может приехать, отказывается в боте, и заявка не висит на нем. Житель одной строкой видит, кто сейчас занимается его заявкой

## Как работает

- Пока работа не сдана на приемку, в карточке исполнителя в боте есть «🙅 Не могу». Бот спрашивает причину, заявка остается в прежнем статусе без исполнителя. Причина сохраняется в переписке с пометкой «Только УК», сотрудникам УК приходит сообщение с причиной и кнопкой в кабинет, карточка исполнителя меняется на «🔀 Заявка №N больше не у вас»
- Жителю об отказе не пишут, у него меняется только строка «Сейчас»
- Строка «Сейчас: ...» под статусом у жителя и в кабинете: «УК принимает заявку»; «УК подбирает исполнителя» (принята или в работе без исполнителя); «проверьте работу» (в кабинете «Житель проверяет работу», у заявки без жителя «УК проверяет работу»). С назначенным исполнителем и у выполненной заявки строки нет
- После отказа исполнитель по категории (файл 31) повторно не назначается, заявку переназначает диспетчер

## Как проверить

Перед началом: аккаунт Б, `demo_admin_1`. В демо-УК исполнителя по категории не закрепить (файл 31), поэтому заявку на себя назначает ссылка исполнителя

1. Тем же аккаунтом подайте жителем (`demo_resident_1`) заявку «Лифт» - у жителя строка «Сейчас: УК принимает заявку»
2. Откройте `demo_executor_1` - заявка назначится на вас, придет карточка с кнопкой «🙅 Не могу»
3. Нажмите «🙅 Не могу» и напишите причину - карточка сменится на «🔀 Заявка №N больше не у вас»
4. Вернитесь в сотрудники ссылкой `demo_staff_1` - в кабинете причина видна с пометкой «Только УК», блок «Исполнитель» снова «Не назначен»
