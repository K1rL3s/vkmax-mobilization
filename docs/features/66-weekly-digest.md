# Недельная сводка

Раз в неделю бот присылает сводку по дому: заявки, объявления, опросы, окно показаний. По умолчанию сводка выключена.

## Как работает

- Кнопка «📊 Сводка за неделю» в главном меню бота (при привязанном доме) показывает сводку или «📊 За неделю в доме ничего не произошло», а если рассылка выключена - еще кнопку «🔔 Присылать по воскресеньям».
- Эта кнопка включает категорию «Недельная сводка» без звука и отвечает «🔔 Сводку буду присылать по воскресеньям, выключить можно в настройках уведомлений». Та же категория есть в «Профиль» -> «Уведомления и звук» (файл 65).
- Рассылка - в воскресенье после 18:00 по времени дома, подтвержденным жителям с включенной категорией.
- Текст: «📊 Неделя в доме: {адрес}», затем строки по непустым разделам: заявки за неделю с двумя главными категориями, число и текст последнего объявления, идущие опросы с явкой, до какого числа принимают показания. Если заявок, объявлений и опросов не было, сводка не приходит.

## Как проверить

Перед началом: аккаунт А с привязанным домом.

1. В боте «📊 Сводка за неделю» - текст сводки (или «ничего не произошло») и кнопка «🔔 Присылать по воскресеньям».
2. Нажмите ее - «🔔 Сводку буду присылать по воскресеньям, выключить можно в настройках уведомлений».
3. «Профиль» -> «Уведомления и звук» - у «Недельной сводки» отмечено «Без звука».
4. Снова «📊 Сводка за неделю» - кнопки подписки уже нет.

## Ограничения

- Сама рассылка приходит только по расписанию, ускорить ее в демо нельзя.
