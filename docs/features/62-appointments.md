# Запись на прием в УК

Житель сам выбирает окно на приеме УК, а сотрудник видит, кто придет сегодня и по какой заявке

## Как работает

- Вход - карточка дома, кнопка «Записаться на прием» (только у подключенного дома). Подтверждение квартиры не нужно
- Часы приема задает админ или создатель организации: день недели, время с-до, необязательный перерыв, длина слота и сколько жителей помещается в слот. Под полями - слоты дня так, как их увидит житель. Сотруднику вместо формы - «Часы приёма задаёт администратор организации». В демо-УК расписание только для чтения: «В демо-УК настройки общие для всех проверяющих и не меняются»
- Житель выбирает день из ближайших 14 и свободный слот, занятые видны бледными. К записи можно прикрепить свою открытую заявку - «Обсудить заявку»
- После записи - экран «Вы записаны на приём» с УК, адресом и заявкой. Запись видна в «Мои записи» и в кабинете УК
- Отменить запись можно до приема, слот сразу освобождается
- Накануне после 19:00 по времени организации бот присылает «📅 Напоминаем: завтра в ЧЧ:ММ вы записаны на прием в УК по дому ...» с кнопкой «📅 Мои записи» (файл 51)
- Кабинет УК, вкладка «Приём» -> «Записи на приём»: список на день со стрелками вперед-назад, у записи с заявкой - переход к ней

## Как проверить

Перед началом: аккаунт А (`demo_resident_1`)

1. Карточка дома -> «Записаться на прием» -> день -> кнопка со временем свободного слота
2. Откроется «Вы записаны на приём» - проверьте адрес УК и время
3. Аккаунт Б (`demo_admin_1`) -> кабинет УК -> «Приём» -> «Записи на приём»: стрелками выберите день записи - в списке запись аккаунта А
4. Аккаунт А -> «Мои записи» -> эта запись -> «Отменить запись», подтвердите - запись пропадет из списка

## Ограничения

- Записать или отменить прием за жителя из кабинета УК нельзя
- Напоминание накануне можно сделать беззвучным, но не выключить
