# Недельная сводка

Раз в неделю бот сам напоминает о доме тем, кто не открывает приложение каждый день: сколько заявок, что нового в объявлениях и опросах, открыто ли окно показаний. По умолчанию сводка выключена.

## Как работает

- Кнопка «📊 Сводка за неделю» в главном меню бота есть только при привязанном доме. Она открывает окно с текстом сводки (или «📊 За неделю в доме ничего не произошло», если событий не было) и, если рассылка выключена, кнопкой «🔔 Присылать по воскресеньям».
- Нажатие подписывает на категорию «Недельная сводка» в режиме «Без звука» и отвечает «🔔 Сводку буду присылать по воскресеньям, выключить можно в настройках уведомлений». Та же категория есть в «Профиль» -> «Уведомления» (см. 55-notification-settings.md): переключить на «Со звуком» или «Выключены» можно и там.
- Рассылка идет раз в неделю по домам, в воскресенье после 18:00 по времени дома, не чаще раза в день на дом. Получают ее только подтвержденные жители дома с включенной категорией.
- Текст: «📊 Неделя в доме: {адрес}», затем по одной строке на непустой раздел - заявки за неделю с топ-2 категорий, число и текст последнего объявления УК, идущие опросы с явкой по квартирам, при открытом окне показаний - до какого числа их принимают. Если заявок, объявлений и опросов за неделю не было, сообщение не отправляется вовсе, даже если окно показаний открыто.

## Как проверить

Перед началом: аккаунт А с привязанным домом.

1. Отправьте боту «📊 Сводка за неделю» из главного меню - если рассылка выключена, откроется окно с текстом сводки (или «ничего не произошло») и кнопкой подписки.
2. Нажмите «🔔 Присылать по воскресеньям» - бот ответит «🔔 Сводку буду присылать по воскресеньям, выключить можно в настройках уведомлений».
3. Откройте «Профиль» -> «Уведомления» - у категории «Недельная сводка» будет стоять «Без звука».
4. Отправьте боту «📊 Сводка за неделю» еще раз - кнопки подписки в окне уже не будет, так как рассылка включена.

## Ограничения

- Сама рассылка приходит только по расписанию: в демо ее не ускорить, «/demo» ее не показывает.
