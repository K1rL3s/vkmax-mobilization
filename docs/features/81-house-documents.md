# Документы дома

УК выкладывает для жителей дома PDF: правила проживания, памятку, отчет. Житель открывает их из карточки своего дома, житель другого дома их не видит

## Как работает

- Кабинет УК -> «Дома» -> дом -> блок «Документы для жителей» под «Чатом дома». Карточка дома в кабинете открыта создателю и администратору (файл 70), сотруднику нет
- В блоке список документов: нажатие открывает PDF, корзина справа -> «Удалить документ?» -> «Удалить». Пустой список: «Документов пока нет»
- Ниже поле «Название» и кнопка «Загрузить PDF». Без названия берется имя файла без «.pdf», название до 120 знаков. Принимается только PDF до лимита размера файла, как у приказа к плановым работам (файл 56); загрузки считаются в общий часовой лимит загрузок пользователя
- В карточке дома у жителя этого дома (с подтвержденной квартирой или без) раздел «Документы» со списком названий, нажатие открывает PDF. Пустой список: «Документов пока нет» с подсказкой, что их выкладывает УК. Тому, кто не живет в доме или заблокирован в нем УК, сервер документы не отдает (`documents: null`), и раздела нет: заблокированному закрыты и объявления
- Ссылка на файл подписана и живет час, карточка дома при каждом открытии выдает новую
- В каждом доме демо-УК лежат «Правила проживания» и «Памятка жителя»: модельные PDF с водяным знаком «ДЕМО». Демо-УК не закрыта: проверяющий может загрузить и удалить документы, в том числе модельные

## Как проверить

Перед началом: аккаунт А на демо-квартире (файл 10), аккаунт Б - администратор демо-УК (`demo_admin_1`). Этот файл проходится до 76

1. Аккаунт А: «Профиль» -> «Карточка дома», внизу раздел «Документы» - «Правила проживания» и «Памятка жителя». Нажмите - откроется PDF с водяным знаком «ДЕМО»
2. Аккаунт Б: кабинет УК -> «Дома» -> первый дом (тот же адрес) -> «Документы для жителей»: те же два документа
3. Аккаунт Б: введите название «Отчет за год», нажмите «Загрузить PDF», выберите любой PDF - он появится в списке. Файл другого формата - ошибка «Приложите документ в формате PDF»
4. Аккаунт А: карточка дома - в «Документах» появился «Отчет за год», открывается
5. Аккаунт Б: у «Отчет за год» корзина -> «Удалить» - документ пропал из списка и из карточки дома жителя
6. Чужой дом: в приложении карточка открывается только для своего дома, поэтому проверка через API - `GET /api/houses/{id}` первого дома демо-УК 1 от аккаунта, который там не живет, отдает `documents: null`, а от аккаунта А - список

## Ограничения

- Только PDF. Порядок - по времени загрузки, переименовать документ нельзя: удалите и загрузите заново
- Жителям не приходит уведомление о новом документе
- Удаленный документ пропадает из карточки сразу, а файл стирается при ночной очистке
- Открытие PDF в мобильном клиенте MAX не проверено, как и у плановых работ
