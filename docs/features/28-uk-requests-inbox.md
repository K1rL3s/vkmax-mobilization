# Входящие заявки в кабинете УК

Сотрудник видит заявки всех домов своей УК в одном списке и из карточки заявки принимает ее, назначает исполнителя и отвечает жителю

## Как работает

- Вкладка «Заявки» кабинета УК. Над списком фильтры «Статус: Все», «Категория: Все» и «Место: Все», каждый открывает шторку с вариантами. Статус: «Все», «Просроченные», «Ждут ответа жителя», «Есть ответ жителя» (файл 29), «Новые», «В работе», «На приёмке», «Закрытые». Место: «Все», «Личные», «Общие» (файл 19), коллективная заявка - по месту первой заявки группы. Рядом с выбранным фильтром кнопка «Сбросить»
- Пустой список - «Заявок пока нет», пустой фильтр - «В этом фильтре пусто» и кнопка «Показать все заявки»
- Коллективная группа схлопнута в одну строку «Коллективная · N квартир». Выше всех стоят заявки, по которым житель попросил руководство («Житель просит руководство с ...», файл 36), затем заявки с плашкой «Опасность: ...» (файл 20), затем просроченные («Просрочена на ...»)
- Карточка заявки: номер, адрес, статус, плашка «Личная» или «Общая», ссылка на исходную заявку у повторной, строка «Сейчас: ...» (файл 33), кнопка следующего статуса («Принять заявку», «Начать работы», «Отправить на приёмку», «Закрыть заявку» - последней нет, если у заявки есть автор-житель: закрывает он), срок, данные обращения (кто, телефон, квартира, время, канал, исполнитель), описание и вложения, блок «Исполнитель», «Ход заявки», «Переписка с жителем»
- Блок «Исполнитель»: «Не назначен. Нажмите на сотрудника - заявка уйдет ему» или «Работает {имя}. Нажмите на другого, чтобы переназначить», у каждого сотрудника число активных заявок. Нажатие назначает сразу
- «Переписка с жителем» - лента по дням с аватаром роли, именем и временем, заметки для УК помечены «Только УК». Под лентой переключатель «Нужен ответ жителя» (файл 29) и поле «Ответ жителю». У заявки без автора - «У заявки нет привязанного жителя. Ответ сохранится в истории, уведомление в MAX не отправится»
- Вкладка доступна создателю, администраторам и сотрудникам. Исполнитель работает только через бота

## Как проверить

Перед началом: аккаунт Б, `demo_staff_1`, заявка о протечке от аккаунта А подана (файл 19)

1. Вкладка «Заявки» -> «Статус: Все» -> «Новые» - в списке заявка «💧 Протечка» с адресом и временем подачи
2. Откройте ее и нажмите «Принять заявку» - статус «Принята», блок «Исполнитель» показывает «Не назначен»
3. В «Переписке с жителем» отправьте ответ, например «Выехал сантехник, ждите в течение часа» - сообщение сразу появляется в ленте, аккаунт А получает его в MAX (файл 26)

## Ограничения

- В списке не больше 100 заявок, остальные видны после сужения фильтра
- Исполнителя в этой карточке назначают вручную. В демо это делает ссылка `demo_executor_1` (файл 32)
