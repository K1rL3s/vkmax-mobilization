# Приглашение арендатора

Собственник пускает в квартиру арендатора без подтверждения через УК: ссылка
сразу делает его жильцом с подтвержденной квартирой, но без начислений и
голоса в опросах.

## Как работает

- Раздел «Жители квартиры» виден только после подтверждения; до этого -
  заметка про это условие.
- Подтвержденному собственнику раздел показывает жильцов («Жителей пока
  нет», если их еще нет) и кнопку «Пригласить в квартиру». У каждого -
  «Собственник» или «Арендатор · по приглашению», плюс «председатель
  совета», «не подтвержден» или «доступ закрыт УК»; своя строка - «Вы».
- «Пригласить в квартиру»: предупреждение об ограничениях арендатора, срок
  (1 день / 3 дня по умолчанию / неделя, максимум 168 часов) и число
  активаций (1 по умолчанию / 2 / 3 / 5). «Пригласить» выдает ссылку с
  кодом, сроком и числом вошедших, кнопками копирования и отзыва.
- Ссылка `flat_<код>` работает и в боте, и в приложении: активировавший
  сразу становится жильцом с ролью «Арендатор», подтвержденным без участия
  УК, бот отвечает «✅ Квартира подтверждена». Отзыв закрывает ссылку для
  новых активаций, но уже вошедших не выселяет.
- Приглашение выдает только подтвержденный незаблокированный собственник;
  если он теряет это право, ссылка перестает работать.

## Как проверить

Перед началом: аккаунт А - подтвержденный собственник новой квартиры (после
файла 08). Понадобится аккаунт Б - тот же, что дальше в блоке 5 станет
стороной УК; здесь он на время арендатор.

1. Откройте «Моя квартира» -> «Жители квартиры» - «Жителей пока нет», ниже
   кнопка «Пригласить в квартиру».
2. Нажмите ее, оставьте параметры по умолчанию и нажмите «Пригласить», затем
   скопируйте ссылку на листе «Ссылка готова».
3. Откройте ссылку аккаунтом Б (при первом входе сначала примите согласие,
   как в файле 01) - переход по ссылке продолжится сам, бот ответит «✅
   Квартира подтверждена».
4. Аккаунтом А откройте «Жители квартиры» снова - в списке жилец с подписью
   «Арендатор · по приглашению», в приглашении - «Вошли по ссылке 1 из 1».
5. Аккаунтом Б откройте «Моя квартира» -> «Жители квартиры» - вместо списка
   заметка: «Вы вошли по приглашению собственника, поэтому не видите
   начисления и не голосуете в опросах».
