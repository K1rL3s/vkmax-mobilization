# QR-коды на лифте, свете и уборке

Житель у сломанного лифта наводит камеру на наклейку в кабине, и мини-приложение сразу открывает форму заявки «Лифт» с подъездом в описании. Панель «соседи уже сообщили» под формой сокращает дубли у УК.

## Как работает

- В кабинете УК на странице «QR-коды дома» (Дома -> дом -> «QR-коды дома») есть переключатель «Подъезды / Лифты / Свет / Уборка». Подъездные коды работают как раньше, остальные печатаются по листу A4 на подъезд с подписью вроде «Сломался лифт? Наведите камеру, заявка откроется в MAX».
- Код объекта - ссылка на мини-приложение `obj_<дом>_<подъезд>_<категория>`. Если житель уже живет в этом доме, приложение выбирает это проживание. Если нет - привязывает дом так же, как подъездный QR: житель становится неподтвержденным жителем дома.
- Затем открывается форма заявки с выбранной категорией и описанием «Подъезд N: ». Панель похожих заявок соседей появляется сразу, потому что категория уже известна.
- Если УК дома не подключена, заявка не уйдет: форма покажет обычный отказ.

## Как проверить

Перед началом: аккаунт Б (`demo_admin_1`).

1. Кабинет УК -> «Дома» -> первый дом -> «QR-коды дома» -> «Лифты» - откроется печатная форма с QR-кодом на каждый подъезд.
2. Отсканируйте код камерой телефона с установленным MAX (или откройте его ссылку напрямую) - откроется форма заявки «Лифт» с текстом «Подъезд 1: ».

## Ограничения

- Переход по `startapp` из камеры телефона на живых Android и iOS еще не проверен.
- Подъезд попадает только в текст описания, отдельного поля у заявки нет.
- Любой, кто отсканировал код, например гость в лифте, становится неподтвержденным жителем дома, как и с подъездным QR.
- Коды лифтов печатаются для каждого подъезда, даже если в доме нет лифта.
