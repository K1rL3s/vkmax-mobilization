# Запуск приложения и диплинки

Мини-приложение открывается только кнопками бота внутри MAX. Своей кнопки
«Назад» в нем нет: экран закрывает стрелка MAX в шапке. Все диплинки
проходят через один разбор внутри приложения.

## Как работает

- Вне MAX (обычный браузер) приложение не открывается: экран «Откройте Жэку
  в MAX» с пояснением, что данные о пользователе оно узнает только из MAX.
- Кнопка бота открывает `startapp`-ссылку, приложение разбирает ее на
  экране `/launch`. `house_<id>` и `qr_<id>_<подъезд>` сразу ведут на выбор
  квартиры (блок 2); `obj_<id>_<подъезд>_<категория>` понимает только
  приложение (файл 39); `flat_<код>` - приглашение в квартиру (файл 09);
  `inv_<код>` - приглашение в организацию, понятно только боту; `reg_<код>` -
  регистрация УК (файл 57); `demo_<роль>_<N>` - демо-доступ (файлы 02-03).
- Без согласия `/launch` показывает тот же экран согласия, что и в боте, и
  продолжает диплинк после него. Приглашение в организацию (`inv_`) отвечает
  «Эту ссылку нужно открыть в боте»; путь в кабинет УК без рабочей
  организации - «Нет доступа к кабинету УК»; просроченная или неизвестная
  ссылка каждого вида отвечает своим текстом с кнопкой «Повторить» и ручным
  способом продолжить.
- Каждый экран, открытый поверх основного, сам обрабатывает системную
  стрелку MAX, а без истории (экран открыли диплинком) стрелка ведет на
  заданный для этого экрана путь. Новый экран всегда открывается
  прокрученным наверх, возврат назад восстанавливает прокрутку.

## Как проверить

Перед началом: аккаунт А, демо-доступ жителя уже выдан (после файла 02).

1. Откройте `https://vkmax.k1rles.ru` в обычном браузере, не в MAX - экран
   «Откройте Жэку в MAX» без кнопок.
2. В боте нажмите «📱 Открыть приложение» - приложение откроется на Главной,
   кнопки «Назад» на самом экране нет.
3. Нажмите круглую кнопку «?» внизу экрана - поверх Главной откроется «Как
   это работает», прокрученный к началу, а в шапке MAX появится стрелка
   назад.
4. Прокрутите вопросы вниз, нажмите стрелку назад в шапке MAX - вернетесь на
   Главную. Откройте «?» еще раз - экран снова откроется сверху.

## Ограничения

- Вне MAX видна только заглушка, поэтому остальные проверки приложения
  делаются внутри MAX.
