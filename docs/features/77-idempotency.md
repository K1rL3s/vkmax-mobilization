# Идемпотентность действий

При плохой сети в MAX кнопку иногда нажимают дважды или запрос уходит повторно. Часть действий защищена ключом идемпотентности: повтор с тем же ключом не создаст вторую заявку и не пришлет второе уведомление. Смена статуса заявки защищена иначе.

## Как работает

- Заголовок `Idempotency-Key` (UUID) генерирует клиент перед отправкой формы и держит его, пока запрос не выполнится успешно: новая заявка и ее повтор, новый опрос, инициатива, предложение, спор по начислению, ответ УК на заявку, заявка по звонку, новое объявление и новый опрос УК. Повтор с тем же ключом и тем же путем не выполняет действие заново, а отдает тот же ответ; ключ для другого пути дает отказ «Ключ уже использован для другого действия», а запрос, который еще выполняется первым вызовом - «Запрос с этим ключом еще выполняется».
- Смена статуса заявки идемпотентным ключом не защищена: вместо этого повторный переход в тот же статус ничего не делает - ни лога, ни события, ни уведомления, ответ приходит тот же. Назад статус не двигается: отказ «Статус заявки назад не двигается».
- Назначение исполнителя такой защиты на сервере не имеет: в кабинете УК от двойного нажатия спасает сама кнопка (повторный тап на уже назначенного исполнителя ничего не отправляет), но два одинаковых запроса напрямую к API создали бы два события назначения.
- Раз в сутки задача очищает ключи идемпотентности старше суток: после этого тот же ключ снова свободен.

## Как проверить

Перед началом: доступен тестовый токен из README «Проверка API».

1. В кабинете УК дважды подряд нажмите одну и ту же кнопку смены статуса заявки (например «Принять») - заявка не меняется дважды, в переписке по заявке не появляется вторая запись.
2. Через curl с тестовым токеном отправьте `POST /api/admin/requests/{id}/reply` дважды с одинаковым `Idempotency-Key` - второй ответ будет таким же, как первый, а в переписке заявки останется одно сообщение, не два.
3. Повторите тот же ключ на другом пути (например `POST /api/admin/requests/phone`) - придет отказ «Ключ уже использован для другого действия».
