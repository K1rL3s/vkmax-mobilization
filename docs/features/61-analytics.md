# Аналитика УК

Дашборд кабинета УК: сколько заявок сейчас открыто и просрочено, как быстро их принимают, откуда они приходят и кто из исполнителей как справляется. Доступен создателю, администратору и сотруднику - исполнитель работает только через бота и сюда не заходит.

## Как работает

- Плитки «Сейчас»: «Активных заявок», «Просрочено по нормативу» (выделяется, если больше нуля) - это текущие счетчики, период на них не влияет. Плитки «За период»: «Среднее время до принятия», «Медиана времени до принятия», «Доля повторных» - если за период нет принятых заявок, вместо числа «-» и подпись «за период нет принятых заявок».
- Графики «Заявки по категориям» и «Заявки по неделям» (последние 12 недель).
- «Откуда приходят заявки»: мини-апп, бот, чат дома, звонок - число и доля каждого канала. У канала «Чат дома» демо всегда покажет 0: подать заявку из чата в этой версии нельзя, канал только для карточек и объявлений.
- «Исполнители»: таблица «Исполнитель / Закрыто / Медиана / Оценка / Повторные» по каждому с ролью исполнителя в организации; если исполнителей нет, вместо таблицы подсказка пригласить их диплинком в настройках организации.
- «Показания»: заголовок «Сдано N из M» по организации, ниже - доля по каждому дому. Кнопка «Напомнить не сдавшим» активна, только пока открыто окно подачи; у демо-УК окно открыто всегда, поэтому кнопка активна в любой момент. Повторное напоминание в тот же день отвечает «Сегодня уже напоминали, следующее напоминание - завтра».
- Период - чипы «30 дней» / «90 дней», по умолчанию 30. Фильтра по конкретному дому на этом экране нет.
- Внизу - ссылка «Сравнение с платформой» на бенчмарк (см. 63-benchmark.md).

## Как проверить

Перед началом: аккаунт Б, роль администратора или сотрудника демо-УК (`demo_admin_1` или `demo_staff_1`), в организации уже есть заявки и показания из более ранних шагов маршрута.

1. Кабинет УК -> «Аналитика» - плитки «Сейчас» и «За период», графики по категориям и по неделям.
2. Пролистайте вниз до «Откуда приходят заявки» - доля по каналам мини-апп/бот/чат/звонок.
3. Откройте раздел «Исполнители» - таблица по исполнителям организации, либо подсказка, если исполнителей еще нет.
4. В разделе «Показания» нажмите «Напомнить не сдавшим» - придет подтверждение о числе напомненных; нажмите второй раз в тот же день - «Сегодня уже напоминали, следующее напоминание - завтра».
5. Переключите период на «90 дней» - плитки и графики пересчитаются на более длинный период.
6. Нажмите «Сравнение с платформой» внизу - откроется бенчмарк.
