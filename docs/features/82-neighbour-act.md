# Акт с соседями

Если УК не пришла проверить отопление, воду или свет, житель вправе сам составить акт о непредоставлении или ненадлежащем качестве коммунальной услуги: его подписывают не меньше двух потребителей и председатель совета дома (п. 110(1) ПП РФ № 354). Время начала нарушения из акта учитывается при перерасчете, если нарушение потом подтвердит проверка УК или экспертиза (п. 111 «г»). Приложение готовит такой акт PDF-файлом в чат с ботом

## Как работает

- Блок «Акт с соседями» в карточке заявки «Отопление», «Водоснабжение» или «Электричество» появляется у открытой просроченной заявки, у заявки, работу по которой житель не принял («Сделано плохо»), и у автозакрытой заявки, по которой житель нажал «Проблема осталась». Показ решает сервер (`RequestCard.can_neighbour_act`, `neighbour_act_due`), по тому же правилу, что и запрос PDF. Кнопка «Акт с соседями (PDF)» сменяется на «Отправили в чат с ботом», и в чат приходит `akt-N.pdf` с подписью «📄 Акт с соседями по заявке №N» и «📝 Впишите замеры, распечатайте и подпишите с двумя соседями и председателем совета дома»
- В PDF: «АКТ о непредоставлении (ненадлежащем качестве) коммунальной услуги» с пометкой, что это акт проверки качества без исполнителя по п. 110(1), строка для даты и времени проверки и составления, адрес с квартирой, исполнитель (УК, ИНН, телефон), услуга (отопление, холодное / горячее водоснабжение, электроснабжение), вид нарушения на выбор, начало нарушения - время подачи заявки с ее номером и сутью, когда истек срок, когда житель не принял работу или когда заявку закрыли без приемки и житель сообщил, что проблема осталась, условие п. 110(1) на выбор (УК не провела проверку в срок по п. 108 или аварийная служба не принимала сообщение), строки для замеров, основание п. 110(1) и п. 111 «г» ПП РФ № 354, строки «Фамилия, имя, отчество», «Кв.» и «Подпись» для составившего акт, двух соседей и председателя совета дома, затем приложение - история статусов заявки. Подписи идут сразу за текстом акта, поэтому длинная история уходит на вторую страницу, а не отрывает подписи. У демо-УК поверх страниц «ДЕМО», в подвале «не для подачи»
- `POST /api/requests/{id}/neighbour-act-pdf` работает как PDF жалобы в ГЖИ (файл 37): только автор (чужая заявка - 404), другая категория, срок не истек или работа не отклонена - 409, бот не может написать жителю - 409. Сервер записывает `REQUEST_EXPORTED` с `format: neighbour_act_pdf`
- Текст нормы: [ПП РФ № 354, разд. X](../norms/pp354-razd10.md)

## Как проверить

Перед началом: аккаунт А в демо-УК, чат с ботом открыт

1. Подайте заявку «Водоснабжение», в блоке «Срок» раскройте «Демо для проверки» и нажмите «Демо: срок истек» - ниже эскалации появится блок «Акт с соседями», над заявлением на перерасчет
2. Нажмите «Акт с соседями (PDF)» - кнопка сменится на «Отправили в чат с ботом», в чат придет `akt-N.pdf`
3. Откройте PDF - адрес, «холодное / горячее водоснабжение», начало нарушения со временем подачи и номером заявки, строки для подписей двух соседей и председателя совета дома, ниже приложение с историей статусов, поверх страницы «ДЕМО»
4. Откройте заявку «Протечка» с истекшим сроком - блока «Акт с соседями» нет
5. Доведите заявку «Отопление» до приемки, нажмите «Демо: закрыть без проверки» - блока нет; нажмите «Проблема осталась» с комментарием и фото, вернитесь по ссылке «Повторно по заявке №N» на исходную - блок «Акт с соседями» есть, в PDF строка «заявку закрыли без приемки потребителем, затем потребитель сообщил, что нарушение не устранено»

## Ограничения

- PDF - черновик: замеры, ФИО и подписи вписывают от руки. Файл приходит только в чат с ботом
- Сервис не знает, проводила ли УК проверку качества: условие п. 110(1) житель подтверждает сам, подписывая акт
