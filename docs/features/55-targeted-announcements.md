# Объявления по подъездам и квартирам

Отключение в одном стояке не касается всего дома. УК отправляет объявление выбранным подъездам или квартирам одного дома, остальные жители его не получают

## Как работает

- Если в «Новом объявлении» отмечен один дом, появляется блок «Кому в доме»: «Всему дому», «Подъездам», «Квартирам». «Подъездам» открывает кнопки «Подъезд 1», «Подъезд 2» и так далее, «Квартирам» - поиск «Номер квартиры или имя жителя»
- Адресное объявление уходит в личные сообщения: «Личные сообщения» включается сам и не снимается. Объявление подъездам с «Чат дома» уходит в чат одним сообщением со строкой «📍 Подъезд N». Объявление квартирам в чат не уходит, «Чат дома» для него скрыт
- Житель видит в ленте только объявления своего подъезда или квартиры, с пометкой «Подъезд 2» или «Для вашей квартиры». В боте под заголовком строка «📍 Подъезд 2» или «📍 Для вашей квартиры»
- В списке объявлений кабинета видно, кому ушло: «... · Подъезд 2» или число квартир
- Квартиры выбирает только администратор УК

## Как проверить

Перед началом: аккаунт А (`demo_resident_1`) - демо-квартира в первом доме демо-УК 1, подъезд 1 (адрес виден на Главной); тем же аккаунтом открыта ссылка `demo_staff_1`

1. Кабинет УК -> «Объявления» -> «Новое объявление», отметьте только свой дом - появится «Кому в доме» с «Всему дому», «Подъездам», «Квартирам»
2. «Подъездам» -> «Подъезд 2» - «Личные сообщения» включится и не снимется. Напишите «Нет ГВС до 18:00», «Отправить» -> «Отправить» - в списке строка «... · Подъезд 2»
3. «Кабинет жителя» -> Главная -> «Объявления» -> «Все» - объявления для подъезда 2 нет
4. Повторите с «Подъезд 1» - объявление появится в ленте с пометкой «Подъезд 1», в боте под заголовком строка «📍 Подъезд 1»
5. Откройте ссылку `demo_admin_1`, в новом объявлении нажмите «Квартирам» и найдите себя по имени - «Чат дома» скрыт. После отправки в ленте жителя объявление с пометкой «Для вашей квартиры»

## Ограничения

- В демо-УК личное сообщение приходит только автору как предпросмотр, даже если он не живет в выбранном подъезде; адресацию видно по ленте жителя
- Объявление подъездам не получит житель квартиры, введенной вручную: у нее нет подъезда. Объявление квартирам получают только подтвержденные жители
- Адресовать можно только один дом. Адресные объявления не попадают в недельную сводку
