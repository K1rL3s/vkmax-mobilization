# Запрос доступа в квартиры

Когда УК нужно попасть в несколько квартир (замена стояка, поверка), она один раз описывает, когда придет, а жители сами выбирают удобное окно

## Как работает

- Создает запрос админ или создатель организации: «Приём» -> «Доступ в квартиры» -> «Запросить доступ». Сотруднику - «Запросить доступ может администратор»
- Форма «Новый запрос доступа»: дом, причина, день (ДД.ММ.ГГГГ, не в прошлом), время с-до, длина окна и число квартир на окно, квартиры поиском по номеру или жителю (только с подтвержденным жителем). Отправка требует подтверждения: «Жители N квартир получат уведомление. Отменить запрос и поменять окна потом нельзя»
- Житель получает одно сообщение с окнами. В приложении это карточка «Доступ в квартиру» в «Мои записи»: причина, дата, кнопка на каждое свободное окно; выбранное подсвечено, занятые тускнеют, выбор можно сменить, пока в новом окне есть место. Неподтвержденному - только «Подтвердить квартиру»
- В боте та же карточка «🔑 УК просит доступ в квартиру ...» с кнопкой на каждое окно «🕐 ЧЧ:ММ», выбранное - «✅ ЧЧ:ММ - выбрано»
- У сотрудника сетка по окнам («свободно N из M» или «мест нет» и квартиры под каждым), блок «Не ответили», в списке запросов - «ответили N из M»

## Как проверить

Перед началом: аккаунт Б после файла 62 (`demo_admin_1`); аккаунт А (`demo_resident_1`) - подтвержденный житель

1. «Приём» -> «Доступ в квартиры» -> «Запросить доступ»: причина, дата (ДД.ММ.ГГГГ), время и длина окна, квартира аккаунта А -> «Запросить доступ» -> подтвердите в листе
2. Аккаунт А -> «Мои записи» -> карточка «Доступ в квартиру» -> нажмите свободное окно - оно подсветится как выбранное
3. Аккаунт Б -> этот запрос: у окна квартира аккаунта А, в списке запросов «ответили 1 из 1»

## Ограничения

- После отправки запрос нельзя отменить или изменить
- Напомнить не ответившим из кабинета нельзя
