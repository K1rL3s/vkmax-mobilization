# Исправления: рассылка, поверка, показания, просрочка

- Рассылка считает отправленными только сообщения, которые MAX принял: отказ
  MAX больше не попадает в счетчик.
- Поверка действует по дату поверки включительно. В этот день бот не пишет
  «Истекла поверка»; уведомление об истечении уходит один раз на следующий
  день.
- Показание сравнивается с прошлым периодом: если за выбранный месяц уже
  отправлено показание, подсказка «Прошлое:» и предупреждение «меньше
  прошлого» берут последнее показание за более ранний месяц, так что
  исправление опечатки вниз не считается ошибкой.
- Заявка на приемке у жителя не считается просроченной: просрочка во входящих,
  в фильтре и на плитке аналитики учитывает только заявки, по которым УК еще
  должна действовать.
