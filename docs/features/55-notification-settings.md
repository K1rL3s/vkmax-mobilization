# Настройки уведомлений

Житель сам решает, как бот напоминает о делах дома: для каждой категории отдельно - со звуком, без звука или никак. Обычно человеку мешает не весь бот, а один вид сообщений, и так меньше людей отключают бота целиком.

## Как работает

- Профиль -> «Уведомления»: четыре строки, «Заявки», «Объявления УК», «Счетчики и поверка», «Недельная сводка» (подробнее - в 56-weekly-digest.md). Каждая строка показывает текущий уровень и открывает общий экран настроек.
- На экране настроек у каждой категории три варианта радиокнопкой: «Со звуком» («Придут со звуком и вибрацией»), «Без звука» («Придут тихо, без звука»), «Выключены» («Бот не будет их присылать»).
- Выбор сохраняется сразу, без отдельной кнопки «Сохранить», и меняет только ту категорию, где нажали. Ошибка сохранения показывает «Не получилось сохранить настройку. Проверьте связь и выберите ещё раз».
- По умолчанию «Заявки», «Объявления УК» и «Счетчики и поверка» - без звука, «Недельная сводка» - выключена.
- Внизу экрана и в профиле напоминание: «Статусы ваших заявок, приёмка работ, записи на приём и запросы доступа в квартиру приходят всегда». Это сообщения по действиям самого жителя: категорией их не выключить, можно только убрать звук у категории, в которую они входят.

## Как проверить

Перед началом: аккаунт А с привязанным домом.

1. Откройте «Профиль» -> «Уведомления» - список из четырех категорий, у каждой текущий уровень.
2. Откройте категорию «Заявки», выберите «Выключены» - выбор применится сразу, без кнопки сохранения.
3. Вернитесь и откройте эту же настройку заново - категории «Объявления УК» и «Счетчики и поверка» остались на прежнем уровне, изменилась только «Заявки».
4. Подайте заявку (или дождитесь смены ее статуса) - уведомление о статусе все равно придет: эти сообщения не отключаются категорией.
5. Верните «Заявки» на «Без звука».
