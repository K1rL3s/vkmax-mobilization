# Подтвержденный телефон жителя

Житель одним касанием делится номером из MAX, чтобы сотрудник УК мог перезвонить по заявке. Номер подтвержден платформой, перепроверять его не нужно

## Как работает

- Профиль, блок «Телефон для связи с УК»: «Подтвердить номер из MAX» открывает окно MAX, после разрешения номер появляется в профиле. Рядом сказано, кто его увидит
- Номер сохраняется, только если MAX подтвердил его подписью. Иначе - «Номер не подтвержден MAX, попробуйте еще раз»
- Сотрудники УК видят номер в заявках жителя по своим домам («Телефон жителя», нажатие звонит), создатель и администраторы - еще и в карточке жителя в списке жителей дома. Исполнители и другие жители номер не видят. В общем кабинете демо-УК номер видит только его владелец
- «Удалить номер» стирает его сразу, «Удалить мои данные» (файл 76) - тоже
- Вне MAX и в клиентах без запроса контакта кнопки нет

## Как проверить

Перед началом: аккаунт А после файла 19 (есть поданная заявка)

1. В мини-приложении (`demo_resident_1`) «Профиль» -> «Подтвердить номер из MAX» -> разрешите доступ - в блоке «Телефон для связи с УК» появится номер
2. Тем же аккаунтом откройте `demo_staff_1` -> кабинет УК -> заявку из файла 19 - строка «Телефон жителя», нажатие звонит. Другие проверяющие этой демо-УК номер не увидят

## Ограничения

- Проверка подписи MAX сделана без официальной документации и на живом клиенте не проверена: подтверждение номера может не пройти
- Поделиться номером можно только в мини-приложении, не в боте
