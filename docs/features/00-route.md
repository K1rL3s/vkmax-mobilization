# Маршрут проверки

Файлы этой папки описывают возможности Жэки по порядку, с 01 до 76. Каждый начинается с того состояния, в котором его оставили предыдущие, а в разделе «Как проверить» перечислены шаги с ожидаемым результатом.

## Что понадобится

- Два аккаунта MAX. Аккаунт А - житель, аккаунт Б - сторона УК. Часть уведомлений не приходит автору действия, поэтому одного аккаунта мало.
- Бот: `https://max.ru/t260_hakaton_max_bot?start=<параметр>`. Демо-параметры: `demo_resident_1` для аккаунта А; `demo_staff_1`, `demo_admin_1` и `demo_executor_1` для аккаунта Б (подробно в 02).
- API без MAX проверяется тестовым токеном, см. [README, «Проверка API»](../../README.md#проверка-api).
- Демо-УК общая для всех проверяющих: ее настройки, исполнители по категориям, команда и часы приема открыты только для чтения. Коллективную заявку с одного аккаунта собирает кнопка «Демо: соседи сообщили» (файл 42).
- На стенде нет ключей Yandex: подсказка категории, распознавание голоса и показаний работают в запасном режиме, это описано в «Ограничениях» соответствующих файлов.
- Шаг 76 стирает данные аккаунта А, поэтому он последний.
