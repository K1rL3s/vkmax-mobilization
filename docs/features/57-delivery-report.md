# Отчет о доставке рассылки

После отправки объявления УК видит, сколько было адресатов и сколько сообщений дошло: «Доставлено 42 из 57».

## Как работает

- Пока рассылка идет, у строки объявления стоит «Отправляется…», список обновляется сам.
- Затем строка меняется на «Личные сообщения · Доставлено 42 из 57». Доставлено - значит MAX принял сообщение; отказ MAX (житель не открывал бота, у бота нет прав в чате) не считается.
- Личные сообщения и чаты домов считаются отдельно, итог - их сумма.
- Если дошло не всем, под строкой объяснение: жители остановили бота, выключили объявления или не открывали его; для чатов - у бота нет прав администратора.
- Отчет виден только в кабинете УК.

## Как проверить

Перед началом: аккаунт Б после файла 54 (`demo_admin_1`).

1. Кабинет УК -> «Объявления» - у старых демо-объявлений «Доставлено N из M» с объяснением недоставки.
2. У объявления из файла 54 строка сначала показывала «Отправляется…», теперь - «Личные сообщения · Доставлено 1 из 1» (в демо-УК личное объявление уходит только автору).

## Ограничения

- Прочтения MAX не отдает, отчет знает только о доставке.
- Если рассылка прервалась, счетчика нет: через 10 минут строка вместо «Отправляется…» показывает число адресатов.
