# Отчет о доставке рассылки

После отправки объявления УК видит, сколько было адресатов и сколько сообщений на самом деле дошло: «Доставлено 42 из 57». Разница - это адресаты, до которых объявление не дошло.

## Как работает

- Рассылка идет фоновой задачей. Пока она не закончилась, в списке объявлений у строки стоит «Отправляется…», а список сам обновляется раз в 3 секунды.
- Когда рассылка закончилась, строка меняется на «Личные сообщения · Доставлено 42 из 57». Доставленным считается сообщение, которое MAX принял; отказ MAX (житель ни разу не открывал бота, чат без прав) не считается.
- Каждый канал считается отдельно: личные сообщения и чаты домов пишут свой счетчик, итог - их сумма. Канал без адресатов (например, у домов нет привязанного чата) сразу получает ноль.
- Если дошло не всем, под строкой объяснение: жители остановили бота, выключили объявления или ни разу его не открывали; для чатов - у бота нет прав администратора в чате дома.
- Сотруднику в бот итог не приходит: он виден только в списке объявлений.

## Как проверить

Перед началом: аккаунт Б после шага 54 (`demo_admin_1`).

1. Кабинет УК -> «Объявления» - у более старых демо-объявлений уже стоит «Доставлено N из M» с объяснением недоставки.
2. Найдите объявление, отправленное на шаге 54: строка сначала показывала «Отправляется…», а теперь - «Личные сообщения · Доставлено 1 из 1» (в демо-УК личное объявление уходит только автору).

## Ограничения

- Прочтения MAX не отдает, поэтому отчет знает только о доставке.
- Если задача упала посреди рассылки, счетчик не появится. Через 10 минут строка перестает показывать «Отправляется…» и возвращается к числу адресатов, как и у объявлений, отправленных до появления отчета.
- Отчет виден только в кабинете УК; жители его не видят.
