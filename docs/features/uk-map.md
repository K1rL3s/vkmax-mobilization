# Карта домов для УК

- Управляющая компания видит все свои дома на карте. Цвет дома показывает
  самое тревожное состояние заявок: красный - авария (протечка еще не
  устранена), оранжевый - житель пожаловался на просрочку, желтый - есть
  просроченные заявки, синий - есть открытые заявки, зеленый - все спокойно.
- На доме видно свежее срочное объявление за три дня, идущий опрос с явкой по
  квартирам, записи на прием на сегодня и долю квартир, подавших показания.
- Администратор дополнительно видит жителей, подтвержденных жителей, запросы на
  подтверждение квартир и привязанный чат дома.
- Фильтры по состоянию, категории, периоду, срочным объявлениям, опросам,
  приему, показаниям и ожидающим подтверждениям считаются на сервере.
- Сотрудники без прав администратора теперь видят список домов организации, но
  без данных о жителях.
