# Карта домов для УК

- Управляющая компания видит все свои дома на карте. Цвет дома показывает
  самое тревожное состояние заявок: красный - авария (протечка еще не
  устранена), оранжевый - житель пожаловался на просрочку, желтый - есть
  просроченные заявки, синий - есть открытые заявки, зеленый - все спокойно.
- На доме видно свежее срочное объявление за три дня, идущий опрос с явкой по
  квартирам, записи на прием на сегодня и долю квартир, подавших показания.
- Администратор дополнительно видит жителей, подтвержденных жителей, запросы на
  подтверждение квартир и привязанный чат дома.
- Фильтры по состоянию, категории, периоду, срочным объявлениям, опросам,
  приему, показаниям и ожидающим подтверждениям считаются на сервере.
- Сотрудники без прав администратора теперь видят список домов организации, но
  без данных о жителях.

## Экран в кабинете УК

- Карта открывается по умолчанию на вкладке «Дома», она теперь есть у всех
  сотрудников УК. Переключатель «Карта» / «Список» оставляет прежний список
  домов; сотрудник без прав администратора видит в нем только адрес и число
  заявок в работе. На вкладку «Заявки» добавлена кнопка, которая ведет на
  карту. Название УК под заголовком «Дома» открывает раздел «Организация и
  сотрудники» из любого вида.
- Сверху ряд состояний «Авария», «Эскалация», «Просрочено», «Открыто»,
  «Спокойно»: это и легенда цветов, и фильтр, можно выбрать несколько.
  Под ним быстрые фильтры «Срочное», «Опрос», «Прием сегодня», «Счетчики
  < 50%» и для администратора «Ждут проверки».
- Кнопка «Слои» открывает подложку и настройки карты, цвет домов (заявки,
  доля квартир с показаниями, для администратора доля жителей), тепловую
  карту заявок за период, категорию заявок, период и слой «Вся платформа»:
  дома других УК и дома без подключенной УК с фильтрами по виду дома, по УК,
  по домам, где жители ждут УК, по доле заявок в срок и по оценке УК.
- Внизу видно, сколько домов показано, сколько домов без координат, и
  кнопка «Сбросить» для фильтров.
- Нажатие на дом открывает карточку: заявки (с переходом в список заявок
  этого дома, при просрочке сразу на просроченные), срочное объявление,
  идущий опрос с явкой, записи на прием сегодня, долю счетчиков, оценку
  жителей, а администратору еще жителей, запросы на проверку и чат. Каждая
  строка ведет в нужный раздел, уже отфильтрованный по дому. Для дома другой
  УК карточка показывает только публичные данные: адрес, УК, ее статистику
  и число жителей, которые ждут подключения.
- Если в одной точке стоят несколько домов, метка выглядит сдвоенной, сверху
  лежит дом с самым тревожным цветом, а нажатие открывает список адресов, из
  которого выбирается нужный дом.
- Все фильтры хранятся в адресе страницы, поэтому ссылку на отфильтрованную
  карту можно открыть заново. Данные обновляются каждые 10 секунд, дом, у
  которого изменились заявки, срочное объявление, опрос или записи на прием,
  коротко пульсирует.
