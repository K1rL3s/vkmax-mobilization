# Аналитика УК

Дашборд кабинета УК: сколько заявок открыто и просрочено, как быстро их принимают, откуда они приходят и как работают исполнители. Доступен создателю, администратору и сотруднику.

## Как работает

- «Сейчас»: «Активных заявок» и «Просрочено по нормативу» (выделяется, если больше нуля). За период: «Среднее время до принятия», «Медиана времени до принятия», «Доля повторных»; без принятых заявок - «-» и «за период нет принятых заявок».
- Графики «Заявки по категориям» и «Заявки по неделям» (последние 12 недель).
- «Откуда приходят заявки»: мини-приложение, бот, чат дома, звонок - число и доля. У «Чата дома» всегда 0: заявку из чата подать нельзя.
- «Исполнители»: по каждому «закрыто», «медиана», «оценка», «повторные». Нет исполнителей - подсказка пригласить их в настройках организации.
- «Показания»: «Сдано N из M» по организации и доля по домам. «Напомнить не сдавшим» активна, пока открыто окно подачи (у демо-УК - всегда); повторно в тот же день - «Сегодня уже напоминали, следующее напоминание - завтра».
- Фильтр «Период»: «7 дней», «30 дней», «90 дней», «Полгода», «Год», по умолчанию 30. Выбор сохраняется при возврате назад. Фильтра по дому нет.
- Внизу - «Сравнить себя с другими УК» (файл 74).

## Как проверить

Перед началом: аккаунт Б (`demo_admin_1` или `demo_staff_1`), в организации есть заявки и показания из предыдущих шагов.

1. Кабинет УК -> «Аналитика» - плитки «Сейчас» и «За 30 дней», графики по категориям и неделям.
2. «Откуда приходят заявки» - доли по каналам.
3. «Исполнители» - список исполнителей или подсказка.
4. В «Показаниях» нажмите «Напомнить не сдавшим» - подтверждение с числом напомненных; второй раз - «Сегодня уже напоминали, следующее напоминание - завтра».
5. «Период» -> «90 дней» - группа плиток станет «За 90 дней», цифры пересчитаются.
6. «Сравнить себя с другими УК» - откроется сравнение.
