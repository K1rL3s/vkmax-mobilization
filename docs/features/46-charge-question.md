# Вопрос по строке квитанции

Житель, у которого выросла одна строка квитанции, задает вопрос о ней в одно касание, не пересказывая цифры. УК получает заявку, где уже есть все, что нужно для ответа: услуга, период, сумма, расчет и изменение к прошлому месяцу.

## Как работает

- В мини-приложении на экране квитанции, в блоке «Построчно», под каждой строкой текущего месяца есть кнопка «Вопрос по строке».
- Она открывает форму заявки с заголовком «Вопрос по строке «Горячая вода» за сентябрь 2026». Житель пишет свой вопрос, например «Почему выросло?», и отправляет.
- Сервер сам собирает описание: «По строке «Горячая вода» за 09.2026: 474.60 руб. (3,5 м³ × 135.60 руб.), к прошлому месяцу +70.00 руб.», затем вопрос жителя и просьбу «Прошу сообщить состав начисления и данные, использованные при расчете».
- Создается обычная заявка категории «Спор по начислению» со сроком 10 рабочих дней; к ней прикладываются фото показаний счетчиков за этот период, если показания сдавали с фото.
- Кнопка «Оспорить начисление» для квитанции целиком осталась.

## Как проверить

Перед началом: аккаунт А (`demo_resident_1`), подтвержденный собственник с историей начислений.

1. «Моя квартира» -> «Начисления» -> откройте любой месяц.
2. У строки «Горячая вода» нажмите «Вопрос по строке», напишите «Почему выросло?», отправьте.
3. Откроется созданная заявка с цифрами в описании - в кабинете УК та же заявка видна в списке заявок. Фото показаний у демо-квартиры нет: ее показания заведены без фото.

## Ограничения

- Вопрос можно задать только по строке, которая есть в квитанции этого месяца; иначе сервер отвечает 409 с текстом «Строки «...» нет в этой квитанции».
- Расчет в скобках есть только у строк с объемом и тарифом (вода, электроэнергия); у строк по площади указана только сумма.
- Если прошлого месяца в истории нет, изменение к нему не пишется.
- Если строки не было в прошлом месяце, вместо изменения пишется «новая строка в этом месяце», как и в мини-приложении.
- В тексте нет ссылок на нормы закона: просьба о составе начисления сформулирована без цитат.
