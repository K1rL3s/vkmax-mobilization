# Регистрация УК

УК подключается сама: находит себя в реестре по ИНН, регистрируется и сразу получает кабинет. Реестр - открытые данные Реформы ЖКХ плюс демо-УК

## Как работает

- Вход - скрытая ссылка бота `reg_<код>`: бот отвечает «🏢 Регистрация управляющей компании открывается в приложении» с кнопкой «🏢 Зарегистрировать УК», она открывает экран «Регистрация УК». Кнопку бот показывает на любой код
- Поле «ИНН организации» (10 или 12 цифр) и кнопка «Найти в реестре»
- ИНН нет в реестре - «Организация не найдена. В реестре нет управляющей компании с таким ИНН. Проверьте цифры». Организация уже зарегистрирована - «Организация уже зарегистрирована. Попросите руководителя пригласить вас в кабинет». Иначе карточка: название, ИНН, лицензия, адрес, телефон, число домов в управлении
- «Зарегистрировать» есть только у свободной организации. Нажатие проверяет код из ссылки: неверный - «Неверный код регистрации организации». Верный - пользователь становится создателем, УК подключается, и открывается вкладка «Заявки» кабинета УК

## Как проверить

Перед началом: любой аккаунт

1. Откройте `https://max.ru/t260_hakaton_max_bot?start=reg_test` - бот ответит «🏢 Регистрация управляющей компании открывается в приложении» с кнопкой «🏢 Зарегистрировать УК»
2. Нажмите кнопку - откроется «Регистрация УК»
3. ИНН `1234567890` -> «Найти в реестре» - «Организация не найдена. ...»
4. ИНН `9900000001` (демо-УК №1) -> «Найти в реестре» - «Организация уже зарегистрирована. ...», кнопки «Зарегистрировать» нет

## Ограничения

- Верный код регистрации не входит в демо-ссылки и выдается командой: без него шаги 1-4 проверяют только экран и поиск по ИНН
- В настоящем продукте регистрацию нужно подтверждать через ЕСИА или письмо с официального домена организации, а не кодом в ссылке
