# Версия сборки и памятка проверяющему

Жюри проверяет стенд без мини-приложения: по curl и README. Стенд отвечает, из какого коммита собран, README перечисляет отказы API с кодами и текстами, а за доступностью стенда во время проверки следит расписание в GitHub Actions.

## Как работает

- `GET /api/healthcheck` отвечает `{"ok":true,"commit":"<хэш>"}`. Коммит запечен в образ при деплое (`BUILD_COMMIT`) и совпадает с хэшем на служебном слайде презентации и коммитом в репозитории. Локальная сборка без `BUILD_COMMIT` отвечает `"dev"`.
- В README раздел «Памятка проверяющему» идет сразу после «Проверки API»: таблица «Действие | Код | Текст» из 11 отказов и готовые команды curl. Отказы API приходят в одном конверте, причина - в `error.detail`.
- Мониторинг: с 30.09 по 14.10 GitHub Actions (`.github/workflows/uptime.yml`) проверяет стенд раз в 15 минут, с 15.10 по 29.10 раз в час: healthcheck и коммит, главную страницу и отказ вебхука без секрета. При сбое бот пишет капитану команды «🔴 Стенд Жэки:» со списком сбоев. Жюри этого не видит.

## Как проверить

Перед началом: тестовый токен из README «Проверка API», `TOKEN=34c63235dea4b1fb95ce89a9f108fc18`.

1. Откройте `https://vkmax.k1rles.ru/api/healthcheck` - ответ `{"ok":true,"commit":"<хэш>"}`, хэш совпадает с хэшем на служебном слайде и коммитом в репозитории.
2. `curl https://vkmax.k1rles.ru/api/me` без токена - 401 «Нужна initData в заголовке WebAppData или тестовый токен».
3. С токеном: `GET /api/requests/1` - 404 «Заявка не найдена»; `POST /api/demo/activate` с `{"number":1}` - 403 «Тестовый токен получает только роль сотрудника демо-УК №5»; с `{"number":9}` - 400 «Поле: ('body', 'number')», а не 422.
4. Загрузка текстового файла в `/api/files` - 400 «Поддерживаются только изображения и видео MP4 или MOV» (файл 81), фото больше 10 МБ - 400 «Файл больше 10 МБ».
5. `curl -X POST -d '{}' https://vkmax.k1rles.ru/webhook` - 403 `{"detail":"Forbidden"}`: без секрета вебхук отвергает maxo.
6. Откройте ссылку `demo_admin_1` и кнопку «🧑‍💼 Открыть кабинет УК» - настройки открыты только для чтения, а `PUT /api/admin/org/settings` отвечает 403 «Демо-УК общая для всех проверяющих, это действие в ней отключено» (файл 79). По `demo_executor_1` кабинет закрыт, API кабинета отвечает 403 «Исполнитель работает только через бота».

## Ограничения

- Лимит 30 загрузок в час (429 на 31-ю) считается в каждом процессе `api` отдельно, поэтому 429 может прийти позже 31-й загрузки.
- Cron GitHub запускается с задержкой 5-20 минут. Оповещение приходит, только если заведены секреты и капитан хоть раз открыл бота.
