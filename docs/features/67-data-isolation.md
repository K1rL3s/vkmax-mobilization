# Изоляция данных между УК

Чужая организация не должна ни увидеть данные другого дома, ни даже понять по коду ответа, что такой дом существует у кого-то другого. С фото заявок и показаний так же: ссылку на файл выписывают только тому, у кого есть на него право, и действует она час. Согласие на обработку данных версионируется отдельно.

## Как работает

- Каждый запрос сотрудника идет с заголовком `X-Org-Id`: если он не сотрудник этой организации - отказ «Нет доступа к этой организации». Если он сотрудник нескольких организаций и заголовок не передан - «Укажите X-Org-Id: вы сотрудник нескольких организаций».
- Внутри своей организации обращение к чужому дому, заявке или группе заявок по id всегда отвечает 404 («Заявка не найдена», «Дом не найден», «Группа заявок не найдена»), а не 403: так одна УК не может даже проверить перебором, существует ли чужой id.
- Фото заявок и показаний отдаются по подписанной ссылке: HMAC-подпись и срок час от выдачи. Ссылка без проверки личности - кто угодно с ней в течение часа откроет файл, а после истечения или при подделке подписи или срока ответ «Файл не найден». Право на файл проверяется один раз, при выдаче ссылки: свои фото жителю, фото домов своей организации сотруднику.
- Согласие на обработку данных версионируется: без него бот не даст привязать дом, подать заявку или сделать другие действия жителя, отказ «Нужно согласие на обработку персональных данных» или «Сначала примите согласие на обработку персональных данных» при привязке дома. Подтверждение более старой или не той версии дает отказ с указанием актуальной версии. После «Удалить мои данные» согласие сбрасывается, и при следующем открытии бот снова его спрашивает.

## Как проверить

Перед началом: доступен тестовый токен из README «Проверка API».

1. Через curl с тестовым токеном отправьте любой запрос кабинета УК с заголовком `X-Org-Id`, указывающим на чужую организацию - отказ «Нет доступа к этой организации».
2. С верным `X-Org-Id` (демо-УК №5) запросите заявку по id, который принадлежит другой организации - ответ 404 «Заявка не найдена», не 403.
3. Откройте в кабинете УК карточку заявки с фото, скопируйте адрес фото из ответа API - ссылка откроется в браузере; измените в ней срок или подпись - «Файл не найден».
4. Через curl отправьте `POST /me/consent` со старой версией согласия, например `{"version": "1.0"}` - отказ с актуальной версией в тексте ошибки; повторите с версией из отказа - согласие примется.
