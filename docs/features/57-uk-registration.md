# Регистрация УК

УК подключается без поддержки: сама находит себя в реестре по ИНН, регистрируется и сразу получает кабинет, куда может звать сотрудников. Реестр - это открытые данные Реформы ЖКХ плюс уже заведенные демо-УК.

## Как работает

- Вход - скрытый диплинк бота `reg_<код>`: бот отвечает «🏢 Регистрация управляющей компании открывается в приложении» с кнопкой «🏢 Зарегистрировать УК», которая открывает экран «Регистрация УК» в мини-приложении. Код здесь не проверяется: кнопку бот показывает на любое значение после `reg_`.
- На экране - поле «ИНН организации» (10 или 12 цифр) и кнопка «Найти в реестре». Подсказка под ней: «Ищем среди организаций в базе Жэки: УК домов из открытых данных Реформы ЖКХ и демо-УК».
- Если ИНН не в реестре - «Организация не найдена. В реестре нет управляющей компании с таким ИНН. Проверьте цифры». Если организация уже зарегистрирована - «Организация уже зарегистрирована. Попросите руководителя пригласить вас в кабинет». Иначе карточка показывает название, ИНН, лицензию (если есть), адрес и телефон, число домов в управлении.
- Кнопка «Зарегистрировать» появляется только для незанятой организации; под ней - «Вы станете создателем кабинета и сможете пригласить сотрудников». Нажатие проверяет код диплинка на сервере: он должен совпадать со скрытым значением `DEEPLINK_ORG_REGISTER`, иначе отказ «Неверный код регистрации организации». При совпадении вызвавший становится создателем, организация помечается подключенной, и приложение сразу открывает вкладку «Заявки» кабинета УК.

## Как проверить

Перед началом: любой аккаунт (регистрировать УК может любой, кто откроет ссылку с верным кодом).

1. Откройте `https://max.ru/t260_hakaton_max_bot?start=reg_test` - код после `reg_` для показа кнопки не важен - бот ответит «🏢 Регистрация управляющей компании открывается в приложении» с кнопкой «🏢 Зарегистрировать УК».
2. Нажмите кнопку - откроется экран «Регистрация УК».
3. Введите ИНН `1234567890` и нажмите «Найти в реестре» - «Организация не найдена. В реестре нет управляющей компании с таким ИНН. Проверьте цифры».
4. Введите ИНН `9900000001` (демо-УК №1) и нажмите «Найти в реестре» - «Организация уже зарегистрирована. Попросите руководителя пригласить вас в кабинет», кнопки «Зарегистрировать» нет.

## Ограничения

- Код `DEEPLINK_ORG_REGISTER` не входит в демо-ссылки: зарегистрировать новую УК может только тот, у кого есть верный код от команды. Шаги 1-4 проверяют экран и поиск по ИНН без него.
- В настоящем продукте регистрацию нужно подтверждать через ЕСИА или письмо с официального домена организации из реестра, а не скрытым кодом ссылки.
