# Эскалация руководству УК

Между «срок истек» и «жалоба в ГЖИ» появилась ступень внутри УК. Житель
одной кнопкой просит руководство управляющей компании вмешаться, и заявка
встает первой во входящих. Инспекция остается последним шагом, а не первым.

Как работает:

- У просроченной открытой заявки карточка жителя показывает два шага:
  «1. Попросить руководство УК» и «2. Жалоба в ГЖИ». Текст для ГЖИ виден
  сразу, право жителя идти в инспекцию от первого шага не зависит.
- После нажатия все, кто связан с заявкой, получают сообщение по одному
  разу. Сотрудники кабинета УК (создатель, администраторы, сотрудники) -
  «⬆️ Житель просит руководство вмешаться: заявка №... просрочена на N ч» с
  адресом и кнопкой «📱 Открыть заявку», назначенный исполнитель - тот же
  текст. Автор получает подтверждение «⬆️ Руководство УК уведомлено о
  просрочке заявки №...», даже если он сам в руководстве УК. Карточка
  жителя пишет «Руководство УК уведомлено 28.09 в 14:10».
- Во входящих УК такая заявка стоит выше остальных просроченных и помечена
  «Житель просит руководство с 28.09 14:10», та же пометка есть в карточке.
  Коллективную заявку поднимает просьба по любой ее открытой просроченной
  заявке, а строка группы показывает самую раннюю такую просьбу.

Где посмотреть в демо: войдите по ссылке `demo_resident_1`, подайте заявку,
нажмите «⏩ Демо: срок истек», затем «Попросить руководство УК». Бот пришлет
подтверждение. Войдите тем же аккаунтом по ссылке `demo_admin_1`: в кабинете
УК заявка окажется наверху входящих с пометкой.

Ограничения: попросить можно один раз и только после срока. Отдельного
статуса нет, только отметка времени; сданная на приемку или закрытая заявка
уходит с верха списка. Доли эскалаций в дашборде УК пока нет.
