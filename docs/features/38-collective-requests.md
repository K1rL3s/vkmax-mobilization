# Коллективная заявка в кабинете УК

Несколько жителей жалуются на одно и то же - протечку в стояке, отключение света в подъезде - и диспетчер должен видеть одну проблему, а не поток одинаковых заявок, которые проще пропустить, чем разобрать по одной.

## Как работает

- Пока заявок одной категории по дому за окно меньше порога (по умолчанию три за 24 часа, настраивается в организации), они остаются обычными. Когда порог набран, они становятся коллективной группой, и открытая заявка той же категории в то же окно тоже входит в нее.
- Во входящих заявках группа занимает одну строку: «Коллективная · N квартир» вместо адреса конкретной квартиры. Строка открывает отдельный экран группы, а не карточку одной заявки.
- Экран группы: адрес дома, статус («Открыта» / «Закрыта»), категория, число квартир, и список «Авторы и заявки · N» - у каждого участника своя строка заявки, как в обычном списке. Заявок пока нет - «Участников пока нет»: «Здесь появятся заявки, присоединённые к коллективной».
- Статус меняется одной кнопкой на всю группу: «Статус изменится у всех участников. Заявки, уже дошедшие до этого шага, останутся в нём». Заявку, которую сотрудник уже продвинул дальше отдельно, групповое действие назад не откатывает.
- Групповое действие доводит статус до приемки, а принимает и оценивает работу каждый житель сам.
- У группы одна карточка в привязанном чате дома (файл 37): число квартир и статус там те же, что на этом экране, и правятся при каждом изменении.

## Как проверить

Перед началом: аккаунт Б после шага 37 - в организации порог коллективных заявок снижен до 2, по дому жителя открыта коллективная заявка «Водоснабжение» на две квартиры.

1. Кабинет УК -> «Заявки»: коллективная заявка видна одной строкой «Коллективная · 2 квартиры».
2. Откройте строку: экран группы показывает «Авторы и заявки · 2» с двумя отдельными заявками.
3. Смените статус группы на «В работе»: кнопка «Применить ко всем» меняет статус у обеих заявок разом.
4. Вернитесь в «Заявки»: строка группы показывает новый статус.

## Ограничения

- Убрать одну заявку из группы или расформировать группу из кабинета нельзя.
- Порог и окно группировки в интерфейсе одни на всю организацию, отдельно по категориям не настраиваются.
