# Данные

Откуда в «Жэке Коммуналкине» дома, УК и справочники, что взято из открытых источников и что сгенерировано для демо. Как данные хранятся и защищаются - в [architecture.md](architecture.md)

## Территория и период

- Москва, Санкт-Петербург и Казань: по 12 крупных улиц в городе, по 55 домов на улицу, всего 1980 многоквартирных домов (660 на город). Список улиц - `STREETS` в `backend/scripts/fetch_seed_data.py`
- Выгрузки Реформы ЖКХ - версия от 01.09.2026. Карточки ГИС ЖКХ получены 12-29.09.2026, дата стоит у каждого дома (`gis_on`) и показывается под паспортом
- История демо-УК - 182 дня до дня запуска сида. Дашборд и сравнение УК считают последние 30 дней, поэтому сид запускают как можно ближе к проверке

## Открытые источники

### АИС ППК «ФРТ» (Реформа ЖКХ)

Основной источник домов и УК, скачивается без регистрации (`reformagkh.ru/opendata/export/<id>`, ZIP с CSV):

- «МКД в региональной программе капитального ремонта» (отчет КР 1.1): выгрузки 184 (Москва), 250 (Санкт-Петербург), 220 (Республика Татарстан). Из них берутся адрес, ФИАС GUID, год ввода, этажность, общая площадь, число и площадь жилых помещений и взнос на капитальный ремонт. Скрипт берет дома с заполненными этажностью, числом квартир и взносом
- «Реестр управляющих организаций по РФ» (выгрузка 1): название, ИНН, телефон, адрес, почта, сайт. Номеров лицензий в реестре нет, поэтому их нет и в сиде
- Карточка дома `reformagkh.ru/myhouse/profile/view/<id>`: число подъездов и блок «Домом управляет». Только она связывает дом с УК. Сейчас карточки закрыты капчей, и часть их при сборе не открылась

Итог в `backend/zheka/seed/data/`: у 552 домов УК из реестра (77 организаций, связь взята, только если название из карточки однозначно находится в реестре). У 1417 домов карточка не назвала число подъездов, оно оценено как `ceil(квартиры / (этажи * 4))` и помечено в паспорте (`entrances_estimated`). Телефоны приведены к `+7XXXXXXXXXX`, заглушки вроде «0», «нет», «Net@mail.ru» и ссылки на чужие сервисы отброшены

Явной лицензии у наборов нет: данные раскрываются по ПП РФ № 731 и публичны по назначению. В репозитории лежит выдержка, полные выгрузки скачивает скрипт

### ГИС ЖКХ (dom.gosuslugi.ru)

Публичная карточка дома отдается без авторизации: скрипт ищет дома улицы одним запросом по ФИАС GUID из Реформы ЖКХ и берет карточку каждого найденного. Из нее в паспорт идут кадастровый номер, износ с датой оценки, состояние дома и класс энергоэффективности (он важнее класса из Реформы ЖКХ). Найдены 1962 дома из 1980, кадастровый номер есть у 1960. Если ГИС ЖКХ не ответила, у дома остаются поля Реформы ЖКХ

УК и договор управления из ГИС ЖКХ не берутся: демо-УК занимают только дома без УК, и новые связи сдвинули бы демо-дома. Приложение в ГИС ЖКХ не ходит, только скрипт сбора

### OpenStreetMap

Координаты домов: Nominatim по адресу, а не найденные им адреса - через Overpass API по улице. Координаты есть у 1919 домов. Данные © участники OpenStreetMap, лицензия ODbL 1.0; атрибуция - в README и на карте. Подложки карты - OpenFreeMap и OpenStreetMap через кэш nginx, адрес по тапу вне справочника - Nominatim в реальном времени

### Справочники в коде

- `backend/zheka/core/city_services.csv` - «Куда звонить»: водоканал, теплоснабжение, энергосбыт, газ, регоператор ТКО, городская диспетчерская и ГЖИ трех городов, 19 строк. Номера взяты с официальных сайтов и сверены 29.09.2026, у каждой строки ссылка на страницу-источник; номер, который не подтвердила официальная страница, не попал в файл
- `backend/zheka/core/pp290.json` - минимальный перечень работ по ПП РФ от 03.04.2013 № 290 в ред. от 07.03.2025: 144 работы. Разбор текста - команды KokInside, сверен с КонсультантПлюс 29.09.2026
- `backend/zheka/core/workdays.py` - выходные, праздники и переносы на 2026-2027 годы для сроков в рабочих днях; источники - в README, раздел «Обращения и ПП РФ № 416»

## Что синтетическое

Все, чего нет в открытых данных, либо персональное, либо биллинг УК:

- Демо-УК: 17 организаций «Демо-УК ...» (`backend/zheka/seed/demo.py`). Пять открываются по демо-ссылкам, по 12 домов у каждой; двенадцать фоновых, по 8-15 домов, видны только на картах и в сравнении УК. В Москве и Санкт-Петербурге по шесть демо-УК, в Казани пять. ИНН не проходят контрольную сумму, телефон `+7 (000) 000-00-NN`, адрес «Адрес вымышлен, организация создана для демо»
- Демо-УК берут только дома без УК из реестра, с координатами и 40-250 квартирами; каждая получает компактный участок в своем городе. Настоящие УК домов не подменяются
- Квартиры: число - из Реформы ЖКХ, площадь - средняя по дому плюс-минус 25%, лицевой счет - номер квартиры с нулями до 10 цифр
- Сотрудники, жители, заявки (около трех в неделю на дом, у фоновых УК одна-две), оценки, опросы, объявления, плановые работы с модельным приказом, записи на прием, сигналы спроса у неподключенных домов. У модельных пользователей отрицательный `max_user_id`, бот им не пишет
- Тарифы одинаковые во всех демо-домах, с повышением в прошлом месяце: холодная вода 59,00 -> 66,05 руб/м3, горячая 285,00 -> 319,00 руб/м3, электроэнергия 7,99 -> 8,93 руб/кВт·ч, содержание 35,00 руб/м2. Взнос на капремонт настоящий, из Реформы ЖКХ по каждому дому
- Счетчики: холодная и горячая вода, двухтарифное электричество. Начисления и показания за 6 месяцев получают квартиры проверяющих (`Д{user_id}` в первом доме демо-УК) и три квартиры первого дома демо-УК №1 со сценариями: скачок расхода, показание ниже предыдущего, поверка через неделю. У остальных подтвержденных квартир - показания только за текущий месяц
- Капремонт, документы и картинки первого дома демо-УК №1 - модельные, картинки сгенерированы
- Отключения в карточке дома (`backend/zheka/core/outages.py`) - вымысел для любого дома: сегодняшнее и завтрашнее отключение выводятся из id дома и даты, организация «Демо-РСО», в приложении подпись «демо-данные»
- Оплата в мини-приложении демонстрационная, деньги не списываются

## Что проверили и не взяли

- Открытые данные ГИС ЖКХ - 123 набора, из них 121 справочник НСИ: домов, УК, лицензий, счетов и начислений там нет. Интеграция для внешних систем - SOAP-канал записи для УК с электронной подписью
- ФИАС / ГАР (53,6 ГиБ) не нужен: в КР 1.1 адрес уже нормализован и рядом ФИАС GUID
- Выписки ЕГРН платные. Порталы data.mos.ru, data.gov.spb.ru и open.tatarstan.ru не открылись или закрыты
- Публичного API для показаний и начислений нет ни в одном из трех городов, поэтому начисления модельные: в реальной работе они пришли бы выгрузкой из биллинга УК

## Как воспроизвести

```sh
cd backend
uv run python scripts/fetch_seed_data.py   # пересобрать seed/data/, холодный прогон дольше часа
just seed                                  # заполнить пустую базу
```

Скрипт кэширует ответы в `backend/.cache/seed/`, повторный прогон идет из кэша. Карточка Реформы ЖКХ, которой нет в кэше, сейчас упирается в капчу: такой дом останется без УК и с оценкой подъездов. Новые улицы добавляются после существующих, иначе демо-дома сдвинутся

Сид в сеть не ходит: читает `seed/data/`, работает одной транзакцией, случайность детерминирована по сущностям, история кончается в полночь UTC дня запуска. На пустой базе в docker - `docker compose run --rm api python -m zheka.seed`, на развернутом боте - `/seed` в личке. Если демо уже есть, сид ничего не меняет; заполнить заново можно только пересозданием базы (`docker compose down -v`, миграции, сид), и это стирает квартиры и роли проверяющих

## Рынок

Оценка рынка на слайде «Путь тиражирования» считается в одной единице - многоквартирных домах - по «Реестру управляющих организаций по РФ» (выгрузка 1 Реформы ЖКХ от 01.09.2026, `export-reestruo-00-20260901.csv`). У каждой организации в реестре есть поле `count_mkd` - число домов в управлении

- TAM: сумма `count_mkd` по всем 49 312 организациям реестра (УК, ТСЖ, кооперативы) - 706 155 МКД
- SAM: та же сумма по 3 335 организациям с 50 и более домами - 470 907 МКД. Порог 50 домов взят из слов эксперта трека о типичной УК с 50+ домами и домовыми чатами без модераторов
- SOM до пилота не оценивается. Фокусный сегмент - одна УК с 50+ домами в Москве, Санкт-Петербурге или Казани, где справочник домов уже загружен

Суммы по реестру - то, что заявили сами организации, дома одной организации могут считаться с ошибкой. Пересчет: выгрузка лежит в кэше `backend/.cache/seed/export-1.zip` после `fetch_seed_data.py`, числа выше - сумма поля `count_mkd` с фильтром `count_mkd >= 50` и без него
