# Что дальше

Что не сделано и куда продукт растет. Текущее состояние: [product.md](product.md)

## Новые механики

- Инцидент по дому: авария или работы как состояние дома. Объявляется в одно нажатие из коллективной заявки, экстренная рассылка идет со звуком и кнопкой «Подтвердить получение», УК видит «подтвердили N из M» и неподтвердившие квартиры по подъездам. Если обещанный срок прошел, жителям уходит «работы просрочены, подать заявку?». Сейчас есть плановые работы с предупреждением в форме заявки и срочные объявления на карте УК
- Заявка из домового чата: ответ на сообщение командой `/заявка` или упоминание бота, черновик доводится в личке по ссылке, в чат возвращаются номер и срок. Канал `chat` в аналитике пока всегда 0
- Живое сообщение о заявке: одно сообщение в личке, которое бот правит при каждой смене статуса, вместо нового сообщения на каждый шаг. Сейчас на месте правятся только карточки исполнителя, приемки и карточки в домовом чате
- Подтверждение квартиры номером телефона: УК загружает соответствие «лицевой счет - телефон», совпадение с подтвержденным номером из MAX подтверждает квартиру сразу
- Небаланс по дому: сотрудник вводит показание общедомового счетчика, дашборд показывает небаланс в кубометрах и рублях и квартиры-кандидаты на перепроверку
- Закрытие окна показаний: сводка сотрудникам на следующий день после окна, разбор аномалий с прошлым и текущим фото рядом и переоткрытием счетчика, выгрузка CSV для биллинга
- Передача дома при смене УК по реестру лицензий: прежняя УК теряет доступ к персональным данным, жители и история остаются с домом, открытые заявки переезжают с новым отсчетом срока
- Хронические точки: заявки одной категории по дому и подъезду или стояку за 6-12 месяцев связываются с блоком капремонта. Нужна адресная точка у заявки: сейчас подъезд попадает только в текст описания
- Закрепленная доска дома в чате: окно показаний со счетчиком сдачи, открытый опрос, ближайшие работы
- Сверка тарифа с региональным потолком, только на строках с единым для региона потолком
- Отчет УК о расходах по дому, когда появится доступ к данным УК

## Доработки текущих функций

- Эскалация вне зоны УК: справочник ресурсоснабжающих организаций по дому, отметка «переадресовано», доля заявок вне зоны УК и доля эскалаций в дашборде
- Показания фотографией в бота: несколько фото одним сообщением и узнавание счетчика по прошлому значению
- Выгрузка заявки документом: `GET /requests/{id}/export` есть, страницы печати нет
- Пометка «от сотрудника организации» на заявке сотрудника: флаг `is_staff_author` в API есть, кабинет УК его не показывает
- Кнопка в мини-приложение у обычных объявлений в домовом чате: сейчас она есть только у объявлений с опросом или документами
- Подсказка категории по тексту в боте: сейчас только в мини-приложении
- Кнопка «Поделиться номером» в боте: сейчас только в мини-приложении
- Скачивание PDF (жалоба в ГЖИ, реестр уведомлений) прямо в мини-приложении, а не только в чат с ботом
- Отмена и правка отправленного объявления и запроса доступа; запись жителя на прием из кабинета УК
- Убрать заявку из коллективной группы или расформировать группу; порог склейки по категориям
- Срок аренды и автозавершение для арендатора
- Сводка УК об истекающих поверках по дому
- Сообщение об ошибке в показаниях после закрытия окна: сейчас есть только категория заявки «Ошибка в показаниях»
- Сумма перерасчета в заявлении и региональные нормативы в «Ваших правах»
- Черновики форм, которые переживают закрытие приложения
- Раздел «Ждут подключения» с домами рядом с домами своей УК, а не со всей платформы

## Интеграции

- Регистрация УК через ЕСИА или письмо на официальный домен из реестра вместо скрытого кода
- Интеграция с биллингом УК: настоящие начисления, квитанции PDF и оплата. Сейчас начисления модельные; формировать их сам продукт не будет
- Отключения от ресурсоснабжающих организаций из реального источника или ручным вводом УК, с уведомлением жителей
- Загрузка настоящих документов дома в кабинете УК
- Юридически значимое общее собрание собственников через ГИС ЖКХ; опросы сейчас - предварительный сбор позиций
- Кабинет оператора платформы со сквозными разрезами по регионам и УК
- White-label бот на токене УК на том же ядре: таблица токенов и роутинг вебхука по боту

## Эксплуатация

- HTTPS и сертификат в репозитории: nginx слушает только 80, TLS настраивается на хосте
- Инструкция по бэкапу базы и файлов
- Проверка на живых устройствах: расшифровка голосовых от MAX, переход по QR из камеры, ссылки `tel:`, вибрация и подтверждение закрытия

## Не берем

- LLM-консультант по ЖК РФ: выдуманная моделью норма бьет по доверию
- Геймификация, маркетплейс мастеров, «отдам даром»: другой продукт
- IoT и умные счетчики, домофоны и шлагбаумы: нет железа, в MAX не показать
- Чат жителей внутри мини-приложения: для этого есть домовой чат MAX
- Справочник соседей по стояку: нет топологии дома, раскрывает квартиры
- Напоминания о задолженности: превращают канал в коллекторский
- Чтение домового чата без явной команды
- Петиции отдельно от опросов и межтенантные заявки на общий двор
