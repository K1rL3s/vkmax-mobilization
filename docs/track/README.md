# Умный город

## Аннотация

В рамках трека «Умный город» вам предстоит создать цифровое решение для жителей, собственников, управляющих организаций и других участников процессов управления многоквартирным домом.

Изучите потребности пользователей, определите актуальную проблему и разработайте чат-бота или мини-приложение в MAX. Покажите ценность решения и потенциал его масштабирования.
